## Visual rubric

Recognition **2**: oversized word fields, emphatic accent and bounded type motion.
Nearest-style distinction **2**: word bands, verb rhythm and selected date/session
panels replace Swiss service rows, practice index and staggered project fields;
composition, navigation and motion all differ. A/B **2**: campaign/manifesto/verbs
versus dates and ruled sessions. Hierarchy **2**: display and practical scales are
clear. Mobile **2**: whole words, controlled weekday scale and complete session
metadata; actual overflow failure fixed. Adaptability **2**: finite motion,
static equivalent and truthful complete programme specified. **12/12**, no zero;
bounded reference evidence and editorial judgment, not a full WCAG guarantee.
