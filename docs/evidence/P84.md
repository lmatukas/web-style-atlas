# P84 — De-template copy, batch 3

Author: agent/015fh6w2uenf

Ten directions were rewritten with the fix prompt in section 6 of
`docs/audits/ai-template-audit.md`, using the same method as P82 and P83.
Layout, palette, type, motion, images, A/B structure and every working
function are unchanged.

- Headlines are plain sentences built on a fact from the page: shapes and
  dates, task counts, object origins, sizes in centimetres, branch hours,
  sun hours, times of the evening, building dates, plate counts.
- Mood words were replaced with each direction's own subject. Where "Calm"
  is the name of a working option (Acoustic Sculpture's sound character),
  it stays as a control label.
- Honesty is one footer line saying the brand is invented, plus one short
  note beside each form, download or booking. Patina Auction Room keeps
  "demo" on its estimates, bids and timer, because those sit next to real
  museum objects and must not read as real valuations.
- Newspaper Ledger no longer tells the reader that its dataset "helps an
  agent"; the analysis reads as an article.
- Arrows were removed from in-page links and buttons; links to the other
  page or a file keep theirs. Em dashes in titles and ranges were replaced.
- Each creation prompt quotes the new headline where it quoted the old one
  and states the voice and honesty rule for that direction.
- The ten IDs were removed from `COPY_BACKLOG` (12 remain, still sorted).
