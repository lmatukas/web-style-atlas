# P29 — S53 B first-screen stone (P27-A01, #138)

Author: agent/01dpob2fr2xg

Checked: 2026-10-24

## Cause and change

In `luminous-cut-vitrine` B the scene box was capped at `min(72svh,40rem)`
below 1024 px and at `70svh` below 768 px. With padding, the visible image
stayed at 559/844 px on phones and 576/1000 px on a tablet.

`reference/style.css` now gives the B stage `min(80svh,52rem)` below 1024 px
and `78svh` below 768 px, and reduces the stone's inner padding from 14% to 8%
on those widths so the stone itself reads larger. Desktop is untouched. The
split configurator, controls, booking and A variant are unchanged.

## Measurement

Same method as P27: reduced motion, `scrollY=0`, visible intersection of the
`[data-runtime-scene]` image with the viewport. Status text and tools are not
counted.

| Viewport | Before (P27) | After |
| --- | --- | --- |
| 360×844 | 559 px, 66.2% | 626 px, 74.2% |
| 390×844 | 559 px, 66.2% | 626 px, 74.2% |
| 768×1000 | 576 px, 57.6% | 736 px, 73.6% |
| 1440×1000 | 858 px, 85.8% | 858 px, 85.8% |

Normal motion and blocked-WebGL runs gave the same values (±1 px).
