# P37 — English conversion: shared tooling

Author: agent/015fh6w2uenf

Checked: 2026-10-25

## What changed

1. **Prompt path rule.** A full prompt is `prompts/<id>/prompt.<language>.md`,
   where `<language>` is `lt` or `en` and equals the brief's `language`.
   `scripts/prompts.mjs` checks it; `schema/prompt-briefs.schema.json` accepts
   `language: "lt" | "en"`. Nothing else in prompt validation was loosened
   (64 KiB, UTF-8, no NUL, no symlink, same style ID).
2. **Language backlog.** `tests/language.test.mjs` reads the `lang` of every
   `styles/*/reference/*.html` and every brief in `prompts/index.json`
   (registry language and file name). `LITHUANIAN_BACKLOG` holds the 26 IDs.
   It fails on an `lt` page outside the list, on a listed style that is
   already fully English, on a style that mixes `lt` and `en`, and on a
   missing or unknown `lang`.
3. **Gallery filter.** Label `Luxury`, options `All directions` /
   `Luxury only`; no `lang="lt"` left in `gallery/template.html`. URL state is
   still `luxury=1`.
4. **Policy.** `core/language-policy.md` gained an "English conversion" section
   pointing to `docs/english-conversion-plan.md`.

## Files outside the card's list, and why

The card lists the prompt validator and schema, but the `lt` path was also
pinned in four other places. Without these edits the first conversion (P38)
could not pass validation or show its prompt in the gallery:

- `schema/style.schema.json`, `schema/index.schema.json`: `prompt_path`
  pattern now `prompt\.(?:lt|en)\.md`.
- `gallery/selection.mjs`: `promptLanguage()`; the A/B fill and short header
  have an English form. The English placeholder line is
  `- Composition: [A OR B; default A].` (documented in `prompts/README.md`).
- `gallery/gallery.js`: accepts either path; the "brief is in Lithuanian"
  notice shows only for an `lt` prompt; the preview `<pre>` gets the prompt's
  `lang`.
- `docs/tasks/P37.md`–`P64.md`: the "Depends on" line now uses the format the
  contract test requires (`P28 (canonical docs/progress.json).`). The queue PR
  (#156) ran only the docs-level CI, so `tests/contract.test.mjs` failed on
  main for these 28 cards. Dependencies themselves are unchanged.
