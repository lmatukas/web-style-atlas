# P20 — įrodymai

## Kaip matuota

Python skriptas (be failų keitimo): kiekvieno `styles/*/reference/index.html` tekstas
be `<script>`/`<style>`, žodžių skaičius ir lietuviškų diakritikų skaičius. Rezultatai
užrašyti `core/language-policy.md`.

## Komandos

- `node --test tests/*.test.mjs` – turi praeiti.
- `npm run validate` – turi praeiti (dokumentacijos pakeitimas).

## Apribojimai

- Diakritikų skaičius yra gera, bet ne tobula kalbos heuristika (trumpi stiliai gali būti
  nuokrypę).
- Politika pasiūlyta, ne patvirtinta: sprendimas dėl 20 angliškų stilių lieka savininkui.
