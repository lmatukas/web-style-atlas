# S13 — Gallery White Cube

Implemented original exhibition-wall and single-work/index compositions with
three original MIT vector paintings and local rights records. No external fonts,
CDN or borrowed artist identity. Local ready catalogue now contains 13 styles;
the public 0.1.0 gallery stays at its previously deployed 12 until a new release.

## Actual checks

- Scoped source validation, build and canonical previews passed. All four PNGs
  are below 1 MiB and current against their complete source hash. Final `npm run
  build -- --style gallery-white-cube` after rendering and `npm run check` passed.
  Building before rendering correctly exposed stale dist copies; rebuilt dist
  after the new canonical PNGs rather than weakening the freshness gate.
- `npm run test:browser -- --style gallery-white-cube`: six actual A/B cases at
  360/768/1440 passed resource, axe, overflow, keyboard focus, control coverage
  and working native disclosure checks. First run exposed inline image links
  with empty rectangles; made artwork links block-level and reran successfully.
- Supplemental real-browser QA passed all six cases: Lithuanian font/glyph
  loading, reduced-motion styles, every local link/fragment/resource destination
  and actual background token consumption under a deliberate CSS-variable
  override. Final B artwork explicitly fills its display field.
- `ATLAS_STYLE_SCOPE='["gallery-white-cube"]' npm run test:gallery`: all three
  subpath/mobile/filter/comparison/prompt cases passed, including both new built
  references. No gallery behavior or shared schema was changed.
- Inspected actual four full-page previews and Quiet Luxury A. Re-inspected final
  B desktop/mobile after enlarging its artwork field. Mobile works remain whole,
  captions attached and dossier below the painting; no text collisions observed.
- Original SVG assets and their local MIT notice resolve and load. Token schema,
  palette contrast pairs, required description sections and A/B data validated.
  `git diff --check` and generated-text/adapter checks passed.
