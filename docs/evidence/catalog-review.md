## Actual usability and consumer replay

Full reference browser audit: `npm run test:browser` (all ready styles; final
result below). It checks A/B at 360/768/1440: resources, errors, axe, overflow,
control coverage, keyboard focus and native disclosures. Existing per-style
custom-control evidence remains relevant; S23 and S24 additionally received
explicit whole-state keyboard and arithmetic checks immediately before merge.

Replayed only the two P10 **choose-for-me** scenarios because catalogue expansion
changes their available candidates. This was a current-fit review plus a browser
replay of the already independently authored P10 outputs, not a new model trial.
Four explicit-ID cases use unchanged sources, so their independent execution and
three-direction same-brief evidence were retained without redundant rebuilds.

- Photo portfolio: retained Cinematic Photo A. New Architectural Monograph
  supplies buildings and analytic figures, not the requested Forest/Water image
  series; Field Notes supplies only the forest/notebook route. The existing
  rights-cleared Forest/Water images remain the stronger exact content fit.
- Workshop directory: retained Institutional Clear A. New Humanist Service is
  suitable for person-led support but its staged help path is a weaker match
  than a searchable catalogue with category/empty/reset states for four workshops.
  Retro Web's personal dated archive is another structurally different option,
  but does not improve this plain community-directory fit.

Both P10 retained sources were materialized into new external directories using
`materialize.mjs`; the photo asset hashes matched. `check.mjs` passed both at
360/768/1440 (six cases): actual copy, loaded resources/images, axe, local
navigation, focus, disclosures and catalogue filter/empty/two reset paths.
Actually inspected the four desktop/mobile replay images. Source selection,
provenance and exact outcomes are recorded in
[the compact replay record](../benchmarks/p13/replay.json).

No new claims of Codex CLI, Claude Code or Bob runtime compatibility. The actual
independent target remains the P10 `gpt-6-luna` alias (snapshot unavailable), with
its original limitations and first-failure history retained. No extra agent/API
calls, package changes or automated-review loops were needed for this audit.

## Remaining bounded limits

Compact secondary diagram/table/log labels are explicitly reflected in 11/12
scores; required values also have text records or an available full diagram.
The glyph footer is an intentional reference QA sample, not content to copy into
a consumer website (P10 records the observed initial copying mistake).
Automated axe and this visual comparison do not establish full WCAG conformance,
universal style originality or reliability across untested native agent hosts.

P14 must still perform the final release metadata, clean-clone reproducibility,
rights/private-data inventory and publication handoff. Current live 0.1.0 content
must not be reported as a deployed 24-style catalogue merely because this source
review succeeds.
