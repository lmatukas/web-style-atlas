  AI-generated websites (copy, type and colour, layout, motion), with seven

  word, fragment pairs, "not just" and numbered labels.

## Method

A script scanned all 100 reference pages, their CSS and scripts: h1/h2
sentence structure, negative parallelism, vocabulary, em dashes per 1,000
words, disclaimer words, eyebrow and numbered labels, italic headings,
arrows, gradient text, backdrop filters, one-sided borders, monospace use,
pointer-following effects, scroll reveals and token fonts. Every quoted
example in the findings was checked against the page text.
