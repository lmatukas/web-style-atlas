# P65 — Correction: Lithuanian words left in converted luxury scripts

Author: agent/015fh6w2uenf

Checked: 2026-10-25

## What happened

P38–P47 checked for leftover Lithuanian by searching for its letters
(ąčęėįšųūž). Words without those letters slipped through. During P48 a word
audit compared each converted file with its pre-conversion version (commit
`a33fa05`) and listed words that appear in both. Six visible strings were
still Lithuanian:

| Style | File | Before | After |
| --- | --- | --- | --- |
| S53 luminous-cut-vitrine | `reference/scene.mjs` | `3D nepasiekiamas` | `3D unavailable` |
| S54 escapement-nocturne | `reference/main.mjs` | `3D neprieinamas` | `3D unavailable` |
| S54 escapement-nocturne | `reference/main.mjs` | `3D kontekstas prarastas` | `3D context lost` |
| S54 escapement-nocturne | `reference/drawing.mjs` | SVG title `… originalus mechaninis laikrodis` | `… an original mechanical watch` |
| S58 velvet-members-hall | `reference/app.js` | pause label `Pristabdyti` | `Pause` |
| S59 patina-auction-room | `reference/app.js` | result count `N objektai` | `N object(s)` |
| S61 scent-ritual | `reference/scene.mjs` | `3D nepasiekiamas` | `3D unavailable` |

The fallback reasons appear in the page status line ("Static fallback: …"),
the SVG title in the static watch image, the pause label after resuming
motion, and the count above the catalogue filters.

## Guard

`tests/language.test.mjs` now also checks every style outside
`LITHUANIAN_BACKLOG` for common Lithuanian interface words in its reference
pages and in script string literals (not code identifiers). A second test
shows that the check catches words with no Lithuanian letters. With the old
files restored, the new test lists exactly the six files above; with the fix
it passes.

Later conversions (P49–P63) run the same word audit before their PR.
