# P67 — Gallery: explain an empty filter result

Author: agent/015fh6w2uenf

Checked: 2026-10-26

## Result

- Owner report: Families "illustrative" + Use cases "data" + other filters and
  the search "services" gave 0 directions with no hint why. Cause: filters
  combine with AND, and no illustrative direction is tagged for data (the four
  illustrative directions are for culture, publishing, campaign, events,
  travel and personal use).
- Every filter option now ends with a count, e.g. "illustrative (4)": how many
  directions that option gives with the other current choices kept. The
  "All …" option shows the count with that filter removed. Option values did
  not change, so URLs and saved links still work.
- When nothing matches, the empty state says "These filters exclude each
  other. Remove one:" and lists each active filter and the search term as a
  button, e.g. "Remove Use cases: publishing → 9 directions", sorted by the
  number of directions it brings back. One click removes that filter only,
  updates the URL and moves focus to that filter. If no single removal helps,
  it points to Reset filters.
- Matching moved into one `matches()` function used by the cards, the counts
  and the empty state, so they cannot disagree.

## Visual check

Screenshots of the empty state at 390 px and 1440 px were taken with
`ATLAS_GALLERY_EVIDENCE` and looked at: the buttons wrap on the phone, there
is no horizontal scroll, and the heading, hint and buttons read in order.
