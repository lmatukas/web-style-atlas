## Changes

- **Gallery order and badge.** `gallery/config.json` lists `new_styles` (the
  eleven S52–S62 IDs in task order) and `new_label`. `scripts/gallery.mjs`
  renders those cards first with a badge, then every other ready card in the
  existing catalogue order. IDs that are not ready are skipped, so fixtures and
  partial checkouts still build. The ordering lives in the gallery build, so it
  holds without JavaScript.
- **Badge text.** The card asks for „Nauja“. The gallery interface is in
  English (“Compare”, “Use this direction”, “Open full preview”), so the badge
  reads **New**; the label is one config value if the owner prefers Lithuanian.
- **Test.** `tests/gallery.test.mjs` checks that `new_styles` has eleven
  distinct ready IDs, that they are the first eleven cards in the generated
  page in that order with exactly eleven badges, and that the remaining 39
  follow in catalogue order. It builds the page in memory, not from `dist/`.
- **Version and docs.** `package.json` and `package-lock.json` 1.3.0;
  `CHANGELOG.md`, `docs/releases/1.3.0.md`, `README.md`, `README.lt.md`,
  `START_HERE.md` and `gallery/README.md` updated. No brand names.
- **Previews.** Full canonical render (all 50 styles) after the version change.
  All 200 PNGs came out byte-identical; only the 200 manifest records changed.

`scripts/gallery.mjs` is outside the card's literal file list but is where the
gallery cards are generated; the change there is limited to ordering and the
badge.
