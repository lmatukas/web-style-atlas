# P85 — De-template copy, batch 4

Author: agent/015fh6w2uenf

Ten directions were rewritten with the fix prompt in section 6 of
`docs/audits/ai-template-audit.md`, using the same method as P82–P84.
Layout, palette, type, motion, images, A/B structure and every working
function are unchanged.

- Headlines are plain sentences built on a fact from the page: clay pieces,
  bars and layers, facets, sessions, seeds and jars, stops, trip lengths,
  works and plates. Kinetic Type keeps its shouted campaign line "MAKE ROOM
  FOR IDEAS." as its one documented telegraphic heading per page.
- Mood words were replaced with each direction's own subject. Option names
  that are working controls stay ("Slow" pace in Trail Composer, the
  "Quiet vase" product name, the "Stillness" preset).
- Honesty is one footer line saying the brand is invented, plus one short
  note beside each form, download or booking. Institutional Clear keeps its
  short top notice and the "not municipal guidance" footer, because the page
  imitates a public service layout.
- Arrows were removed from in-page links and buttons; links to the other
  page or a file keep theirs. Em dashes in titles were replaced.
- Each creation prompt quotes the new headline where it quoted the old one
  and states the voice and honesty rule for that direction.
- Seven IDs were removed from `COPY_BACKLOG` (5 remain, still sorted).
  Luminous Cut Vitrine, Institutional Clear and Gallery White Cube already
  passed the lint, so they had no backlog entry; their copy was still
  reviewed against the audit and tidied.
