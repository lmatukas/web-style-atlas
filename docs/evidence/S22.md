# S22 — Architectural Monograph

Field / Measure is a fictional independent publication studying two actual
buildings: Edith Farnsworth House and the Glass House. A is a single-building
photograph/interpretive-plan/detail reading; B is an accessible project index
followed by two unequal building spreads. No project authorship implied.

## Rights and factual sources

Two actual photographs by Carol M. Highsmith, Library of Congress, reproduction
numbers LC-DIG-highsm-04118 and LC-DIG-highsm-04817. Inspected source records:

- https://commons.wikimedia.org/wiki/File:Farnsworth_House_2006.jpg
- https://commons.wikimedia.org/wiki/File:Glass_House_2006.jpg
- Primary dedication: https://wwws.loc.gov/rr/print/res/482_high.html
- Building history: https://edithfarnsworthhouse.org/history-farnsworth-house/
- Building account: https://theglasshouse.org/explore/the-glass-house/

The primary Highsmith rights statement identifies her photographs as public
domain; both Commons records identify photographer and reproduction numbers.
Bundled assets/RIGHTS.txt records sources and local transformations: 1280px
source derivatives, monochrome 64-step palette, metadata removed, lossless WebP.
A labeled CSS detail crop uses the same photograph, not another viewpoint.
Original MIT SVG is an interpretive relationship plan, explicitly not measured,
not to scale and not a construction record. Corrected its enclosure bracket to
exclude the covered threshold. No invented dimensions or copied archival plan.

Initial direct image requests returned 403. Wikimedia's response explicitly
requested a descriptive User-Agent; using the project-identifying agent allowed
the published derivatives to download. No login, access gate or robot challenge
was bypassed. Direct LOC record fetches were unavailable; indexed records,
Commons provenance and the accessible primary collection rights statement were
used. The two official building accounts support identity/architect/year.
