# P21 — įrodymai (tarpinis)

Užduotis: style.md frontmatter formato suvienodinimas. Šis įrodymų failas dengia pirmą žingsnį: kanoninio PNG generavimo darbo eigą, nes P21 buvo blokuojamas dėl jos.

## Padaryta

- Pridėta `.github/workflows/previews.yml`: rankinis paleidimas (`workflow_dispatch`), parametrai `branch` ir `style` (tuščias = visi). Naudoja Node 24.19.0 ir Ubuntu 24.04 runner'į, įdiegia užrakintą Chromium headless shell, paleidžia `npm run previews`, `npm run check`, ir commit'ina tik `styles/` bei `catalog/` pakeitimus į nurodytą šaką. Atsisako `main`.
- `docs/CI.md`: pridėtas skyrius „Regenerate previews in GitHub Actions“.

## Lokalūs patikrinimai

- `node scripts/ci.mjs validate` → PASS.
- `node --test tests/*.test.mjs` → žr. PR.

## Dar nepadaryta (P21 lieka atviras)

- Workflow dar nebuvo paleistas. Pirmas paleidimas turi įrodyti, kad PNG atitinka kanoninę aplinką (`npm run check`).
- Frontmatter pakeitimai `styles/*/style.md` (27 JSON, 12 YAML) dar nedaryti. Jie pakeis preview šaltinio hash, todėl PNG bus perkuriami tuo pačiu workflow.
- Vizualinė PNG patikra dar nepaleista (`not_run`).
