## Peržiūros ir šriftai

- Kanoninė aplinka (`scripts/preview.config.mjs`) fiksavo Node, OS, Playwright ir naršyklę, bet ne šriftus. Senieji PNG buvo renderinti mašinoje su kitais atsarginiais šriftais.
- GitHub ubuntu-24.04 runner'is (`fc-match`, workflow anotacijos): Arial → Liberation Sans, Courier New → Liberation Mono, Georgia, Trebuchet MS ir bendrinės šeimos → DejaVu.
- Savininko sprendimas (variantas A): runner'io šriftai yra kanoniniai. `CANONICAL_FONTS` juos fiksuoja; `launchCanonical` atsisako hosto, kurio `fc-match` rezultatai kitokie. `docs/CI.md` papildytas skyriumi „Canonical fonts“.
- Workflow `previews.yml` paleidimai: 39723856539 (27 stiliai po frontmatter pakeitimo), 39724545914 (visi 39 po šriftų užfiksavimo). Abu success, įskaitant `npm run check`.
- Determinizmas: antrame paleidime 25 iš 27 jau renderintų stilių PNG sutapo baitas į baitą. `soft-spatial` B variante skyrėsi 4 ir 1 pikselis, po 1 spalvos žingsnį iš 255 (tikėtina, blur triukšmas).
