# S03 — Neo Brutalist

Original Shoutmoot event: poster/manifesto composition A and framed,
filterable two-day programme B. Semantic yellow/violet palette, heavy type,
thick exposed borders, hard shadows, four canonical previews and complete
style/layout contracts. All writing and CSS geometry are original; no external
assets, fonts, ticketing service or data collection.

Actual PASS: source validation, build, targeted preview generation and read-only
freshness check. Six Chromium A/B combinations at 360/768/1440 passed resources,
links, one-h1/main structure, no horizontal overflow, keyboard skip/focus,
native disclosure, reduced motion, loaded glyph sample and a real token override.
Additional real mobile test toggled Day 02 by keyboard Enter, verified pressed
state, hidden Saturday sessions, visible Sunday sessions and polite status,
then restored Day 01 by click. No unsupported accessibility certification or CI
claim.

Actually inspected preview.png, preview-mobile.png, preview-alt.png and
preview-alt-mobile.png. A has a huge left poster, offset violet circular stamp,
strong date band and numbered manifesto. B exposes time/title/format/location
in a thick programme grid and stacks each session legibly on mobile. Borders
remain inset, typography stays inside the viewport and practical text remains
subordinate without becoming tiny. The two compositions are clearly distinct.

Rubric: recognition 2, distinction 2, A/B 2, hierarchy 2, mobile 2, adaptation 2
= 12/12. Actual comparisons: Swiss Grid uses hairline alignment and quiet service
rows rather than these frames, bands and interactive day navigation. Editorial
Journal uses literary serif reading and narrow continuous paragraphs rather
than poster words and short public notices. Planned Bauhaus Geometric is not
claimed as an existing neighbor. The next task must validate the three-style
pilot with the same neutral brief before more style production.
