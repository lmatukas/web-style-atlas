# P06 — First working static gallery

Build now emits a complete untracked dist/ from the ready index, gallery sources,
ready style directories and shared core files. Original individual references,
local assets, source descriptions and four preview paths retain their relative
structure. Initial source build remains independent of preview generation;
publication check requires fresh images, and a second build syncs them to dist/.
No backend, accounts, payments, extra style or external frontend dependency.

Gallery: labeled search, family/use/density/image/complexity facets, live result
count, reset/empty state, native detail disclosures, real references and source
links, A/B and desktop/mobile switching. Search/filter/view state persists in URL
query parameters and reloads. Links/cards are server-generated, so basic browsing
survives absent JavaScript. Dynamic metadata uses textContent and embedded JSON
escapes '<'; no metadata is injected as executable markup.

Actual checks:
- 60 unit tests PASS, including two new clean-rebuild/obsolete-file/symlink cases.
- 3 real renderer fixture tests PASS after integrating the generated gallery.
- 2 real gallery browser cases PASS: 390px under /atlas/; all six A/B reference
  pages at 360px under /repo/. Tests cover no overflow/errors/missing resources,
  keyboard skip/focus, filters/empty/reset, query reload, B/mobile image decoding,
  disclosures and actual stylesheet loading.
- Source build, regenerated package-dependent previews, full read-only check and
  staged whitespace pass. A clean dist/ rebuild is byte-identical. dist/ is ignored.
- Actually viewed full gallery desktop/mobile captures: three different thumbnails,
  readable labels, intentional one-column mobile cards and clear empty-state space.

The browser test exposed an overly broad accessible name on nested select labels.
The production markup was fixed to separate label/select, and the targeted test
passed. Fixture/setup changes include gallery sources and rebuild dist after
rendering; they preserve the source-first pipeline rather than weakening gates.
No browser limitation was hidden as PASS. No public hosting/deployment or full
P08 accessibility gate is claimed. Compare/selection-prompt controls belong to P07.
