# P08 — Truthful and bounded quality gates

Local workflow readiness verified before publishing this PR. The actual GitHub
run is separate evidence and must be inspected on the exact PR head before merge;
its run URL/result will be recorded in the canonical task checks. This document
does not claim an unobserved GitHub run passed.

One pull_request/manual workflow, standard ubuntu-24.04, exact Node 24.19.0,
contents:read, no push duplicate/schedule/deploy. Scope and source jobs are capped
at 10 minutes, browser at 15; concurrency cancels superseded PR runs. All caches
are explicitly disabled. Only small failure text/PNG diagnostics can upload with
retention-days 1. Success uploads nothing. No paid capacity, LFS or AI review.

A dependency-free dispatcher checks registry/board and selects actual changed
styles/shared dependents. Pure docs/tracking skip package install, build and
browser. Gallery/index changes test the gallery and changed references. Source
validation determines whether drafts actually require a browser. Manual full
validation covers all ready pages. Canonical setup and authoring commands are
in docs/CI.md.

Committed generated text is compared before build can mask drift. Selected
preview hashes are checked read-only; CI never generates baselines or commits.
The normal build recreates untracked gallery output, and git diff verifies that
committed data was not rewritten. Shared Markdown/consumer instructions are
excluded from render provenance only because the preview server now explicitly
forbids rendering them; renderable shared resources still invalidate dependents.
This fixes the earlier overly broad documentation dependency without hiding a
render input. Tests cover this boundary.

Actual local execution of the same full source/browser gate:
- Clean locked npm ci PASS: 9 development packages including axe-core 4.12.1.
- All 69 unit tests PASS, including 6 CI-specific scope/workflow/drift/draft cases.
- All 3 gallery browser cases PASS under subpaths, with real filters/comparison,
  clipboard and reference loading.
- Real quality gate PASS for 21 combinations: 3 styles × A/B × 360/768/1440 plus
  gallery at those widths. WCAG-tagged axe results, initial visible keyboard
  focus, control obstruction, native disclosures and actual day filtering checked.
- All 4 browser fixture cases PASS: 3 renderer/provenance cases and deliberately
  broken overflow/unlabeled-button/covered-control cases. Existing source/token
  negative fixtures cover malformed data and contrast, while renderer fixtures
  cover missing images/fonts/scripts and stale source/output manifests.
- Full build, fresh 12-preview manifest, read-only check and whitespace PASS.

The new geometry test initially measured multiline inline links incorrectly and
then retained the focused skip link over the header. Inspecting the actual
failure image confirmed the obstruction was caused by test focus state. It now
uses a real client rectangle, verifies initial focus, then blurs the temporary
skip link before inspecting pointer geometry. A separately obstructed real
button still fails, so the gate was corrected without disabling its protection.

Automation detects a useful subset of accessibility issues; it is not WCAG
certification and does not replace the actual visual rubric or editorial review.
Actual CI execution may still expose environmental or permission blockers; leave
those visible rather than treating local readiness as a remote PASS.
