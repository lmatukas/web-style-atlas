contract requires matching renderer/audio declarations for new prompt-backed
styles. CI runs real runtime acceptance for every ready declared A/B page;
older styles remain on their existing checks. No rendering dependency added.

96-preview freshness checks passed with 24 ready styles. The real canonical
Chromium fixture exercises native depth-tested WebGL, actual opt-in Web Audio,
normal/reduced/no-WebGL/no-audio modes, pause/mute, hidden/offscreen suspension,
context loss, working finish selection in fallback, cleanup and byte-identical

the original fixture now changes its hidden attribute explicitly. The real tests
passed after that correction. No required check was replaced with a mock result.
