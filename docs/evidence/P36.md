## The font rule

`scripts/distinctiveness.mjs` adds `classify()`. A shared-asset group is
accepted only when **every** copy in it:

1. sits at `assets/fonts/<family>/<file>.(woff2|woff|ttf|otf)`;
2. has a licence file (`OFL.txt` or `LICENSE.txt`) in that family folder;
3. belongs to a style whose `assets/RIGHTS.txt` names the family.

Anything else, including photos, other binaries and a group mixing a font
with a non-font, stays a `shared-asset` warning under the zero-duplicate
rule. `warningsFor()` (used by `validate`) returns only real warnings;
`acceptedFor()` returns the accepted list.

Two new tests in `tests/distinctiveness.test.mjs`: a font group passes only
with both licence folder and RIGHTS naming, and fails when either is missing;
photos, mixed groups and look-alike paths always warn.
