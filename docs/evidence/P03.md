## Canonical generation and commands

Configuration: `scripts/preview.config.mjs`.

- Ubuntu 24.04 x64, Node v24.19.0.
- Playwright 1.62.1 with Chromium Headless Shell 151.0.7922.34 (revision 1234).
- DPR 1, en-US, UTC, light color scheme, reduced motion.
- Clock starts at 2026-01-01T00:00:00.000Z, advances exactly 1000 ms and freezes;
  Math.random has a fixed seed. CSS/Web Animations are disabled for screenshots.
- Every capture uses a fresh browser context, no service workers, no external
  network or WebSockets, and eagerly loads images and awaits fonts/decoding.
- Full-page PNGs are bounded to 1 MiB each and a 128 MiB decoded pixel budget.
  Output images contain no wall-clock timestamps. No successful test artifacts,
  binaries, traces or videos are committed.

On the canonical host:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npx playwright install --with-deps --only-shell chromium
npm run build
npm run previews -- --style <id>
npm run check
npm run test:browser -- --style <id>
```

`npm run previews -- --all` considers all authored styles, but renders only
missing/stale ones. Prefer the style scope for routine work. `--all` is required
when migrating an existing manifest to a different configured environment.
Drafts may be rendered explicitly once both references and generated token CSS
exist; unfinished drafts without reference pages must be completed before an
all-style generation. Changing draft to ready changes the source hash, so run
build/previews/check again. Build always remains independent of screenshots.

`npm run test:unit` requires no browser. `npm run test:previews` is the separate
real fixture suite; a missing browser fails it explicitly. `npm run test:browser`
loads all ready references, or a single selected draft/ready style, without
writing baselines. This is resource/PNG smoke, not the future full P08 browser
quality gate. Both CLI render/smoke commands exit 2 for `NOT_RUN`, 1 for failures,
and 0 for successful rendering or explicitly reported already-current previews.

The normal CDN download returned a 195-byte HTML response instead of an archive
in this environment. The official Chrome for Testing Google Storage URL for the
same pinned build provided the genuine ZIP; it was installed only in the local
browser cache. Chromium's actual version was verified before tests. This is a
local installation workaround, not a new project host or CI download policy.

## Freshness and remaining limits

A source hash conservatively includes every file of the selected style except
its four generated PNGs, all shared core/assets resources, renderer/server/config,
the path helper, package.json, package-lock.json, environment and viewport data.
Resources outside that closure are blocked. Changes to shared code/config/locks
invalidate dependent previews. Each record stores the actual PNG hash and full
pixel dimensions. Duplicate/missing combinations, wrong filenames, stale hashes,
invalid PNGs and noncanonical environments fail publication checks.

Generation invalidates stale records before launching and stages all four PNGs
in memory before publishing a style. A render failure cannot retain a success
record for the selected stale style. Writes are atomic for the manifest; a disk
failure during PNG writes may leave untracked files, which checks reject.

System font rendering remains tied to the canonical Ubuntu host and installed
fonts; no cross-OS pixel identity is promised. Provenance proves source/output
correspondence, not aesthetic quality. The fixture is deliberately a test page,
with a large gap to prove full-page capture, not an atlas design or an evaluated
style. Static reference captures reject nested frames/audio/video; use local
static imagery. P08 still owns 360/768/1440 overflow, controls, accessibility and
bounded changed-scope GitHub workflows. No GitHub CI run is claimed.
