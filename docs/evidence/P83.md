# P83 — De-template copy, batch 2

Author: agent/015fh6w2uenf

Ten directions were rewritten with the fix prompt in section 6 of
`docs/audits/ai-template-audit.md`, using the same method as P82. Layout,
palette, type, motion, images, A/B structure and every working function are
unchanged.

- Headlines are plain sentences built on a fact from the page. Neo Brutalist
  keeps one shouted headline per page, because loud type is its documented
  voice; its other headings now state facts about the sessions.
- Mood words were replaced with each direction's own subject: weave names
  and thread colours, notes and sample sizes, case and movement figures,
  courses, times and tables.
- Honesty is one footer line saying the brand is invented, plus one short
  note beside each form, download or booking. Industrial Spec keeps its
  "not for manufacture" notes next to the drawings, since those carry a real
  safety meaning; the repeated "fictional" mentions were removed.
- Real city names were replaced: Neo Brutalist's venue is now on an
  invented "River Street", and Escapement Nocturne's salons are "Old Town"
  and "Harbour". The date logic still uses the Europe/Vilnius time zone,
  which is a technical setting, not a venue.
- Arrows were removed from in-page links and buttons; links to the other
  page, a file or a download keep theirs. Em dashes in titles, ranges and
  labels became middle dots, colons or en dashes.
- Each creation prompt quotes the new headline where it quoted the old one
  and states the voice and honesty rule for that direction.
- The ten IDs were removed from `COPY_BACKLOG` (22 remain, still sorted).
