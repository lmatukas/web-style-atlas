## Result

New light luxury direction `luminous-cut-vitrine` for high jewellery. Two
reference pages, a Lithuanian creation prompt, local OFL fonts, an original
native WebGL round brilliant (57 computed facets, studio environment, double
pavilion reflection and per-channel refraction for fire), a six-claw head, band,
bail and chain, and renders of the same code for the static fallback and the
collection plates.

- A — collection vitrine: centred stone in an ivory vitrine ring, three 4:5
  portrait plates (ring, pendant, earrings, middle lowered), an inline facet
  drawing generated from the same proportions, three services and a visit booking.
- B — single piece "Aušra": sticky stone stage with claws, metal / stone size /
  ring size / engraving choices with a live band preview, exact demonstration
  price, specification list and the same booking preset to the piece.

Invariants: one stone in empty ivory; a vitrine ring and corner text instead of
a hero card; Bodoni Moda with Alegreya Sans and spaced labels; colour only from
the stone and the chosen metal; a quiet but complete service.
Anti-patterns (style.md): a product grid in the vitrine; gold gradients, glitter
or constant spinning; fake commerce urgency.

## Name and rights

- Demo name "Quenvaire": exact searches for "Quenvaire" and "Quenvaire jewellery
  brand company" on 2026-10-23 returned no company or product with this name
  (only unrelated place and surname results). A first candidate, "Ilvenne", was
  rejected because a similar-sounding jewellery label exists. Bounded web check,
  not a trademark clearance.
- Fonts: Bodoni Moda (variable instance wght 400, opsz 28) and Alegreya Sans
  Regular/Medium from the upstream OFL folders; no Reserved Font Names, so subsetting
  is permitted. Lato was considered and rejected because of its Reserved Font Name.
  Full OFL.txt beside each family; 54,380 bytes in total; Lithuanian cmap verified.
- Renders: `stone.png` and six WebP files are made by `tools/render-stills.mjs`
  from `reference/gem.mjs`. The asset policy treats every raster as a photograph
  and requires CC0/PD, so these original renders are dedicated under CC0-1.0 in
  `assets/RIGHTS.txt`; the drawing code stays MIT. No photographs, imported models,
  textures or AI images. Raster total 258516 bytes.
- Owner decision 2026-10-23 allows AI imagery under the plan's conditions; none was
  needed here.
