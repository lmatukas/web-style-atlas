# P15 — Full creation prompt integration

## Result

Optional `prompt_path` in style metadata and the generated ready index links
one style to `prompts/<same-id>/prompt.lt.md` and its public brief registry.
All registered briefs receive schema/source checks. Build publishes only the
linked ready prompt, removes obsolete copies and excludes the planning registry.
No new real style is published by P15: 24 ready styles and 15 planned briefs remain.

The card offers a keyboard-accessible full-text preview. Selection loads the
complete local brief, resolves A/B in its composition field and retains the
project placeholders and every other source instruction. Preview uses textContent;
HTML inside the Markdown stays inert. Clipboard success and manual fallback use
the identical complete text. Loading failure disables copying and offers retry;
late A/B requests cannot replace the current selection. Existing styles retain
their selection prompt. Consumer instructions describe the optional route.
