# P86 — De-template copy, batch 5

Author: agent/015fh6w2uenf

The last ten directions were rewritten with the fix prompt in section 6 of
`docs/audits/ai-template-audit.md`, using the same method as P82–P85.
Layout, palette, type, motion, images, A/B structure and every working
function are unchanged. With this batch `COPY_BACKLOG` is empty: every
direction in the atlas passes `tests/copy-tells.test.mjs` with no exemption.

- Headlines are plain sentences built on a fact from the page: what the
  studio makes, books and themes, spaces, library visits, what each
  photograph shows, tracks and minutes, seasons, a table and a cup.
  Y2K Chrome keeps its release title "AFTER THE SIGNAL." and Midnight
  Vestibule its "The night begins in the lobby." as their one documented
  display line, since both are names of the thing on the page.
- Mood words were replaced with each direction's own subject. Editorial
  Journal is a lifestyle magazine whose essay is about making room; its
  essay text stays, but its headlines now come from concrete details in the
  story.
- Honesty is one footer line saying the brand is invented, plus one short
  note beside each form, download or booking. Cinematic Photo keeps its
  exact credits for the two real photographs (a CC0 photographer and an NPS
  public-domain image); only the invented journal copy changed.
- Swiss Grid no longer names a real city.
- Arrows were removed from in-page links and buttons; links to the other
  page or a file keep theirs. Em dashes in titles and ranges were replaced.
- Each creation prompt quotes the new headline where it quoted the old one
  and states the voice and honesty rule for that direction.
- The last five IDs were removed from `COPY_BACKLOG`, which is now `[]`.
  Midnight Vestibule, Light Environments, Y2K Chrome, Retro Web and
  Editorial Journal already passed the lint; their copy was still reviewed
  against the audit and tidied.
