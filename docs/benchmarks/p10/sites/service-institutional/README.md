# Plainword

A single-page, dependency-free website for the fictional Plainword editorial service.

## Run locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Stop the server with `Ctrl+C`.

The service search filters local page content only. Navigation and service links point to sections on this page; no form or network service is used.
