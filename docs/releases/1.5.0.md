# Web Style Atlas 1.5.0

50 ready directions, 100 working layout variants (A and B) and 200 current
desktop/mobile previews. Target: https://lmatukas.github.io/web-style-atlas/.
The package remains private; this is a Git source catalogue, not an npm package.
[1.4.0 release notes](1.4.0.md) are preserved.

**Status: merged, waiting for the owner's publication run.** The run and live
checks are recorded at the end of this file after publication.

## What changed since 1.4.0

Every direction now has a full creation prompt, and every page has been
rewritten so it no longer reads like a standard AI-generated website.
Layout, palette, A/B structure and working functions are unchanged apart from
the items listed here.

| Area | Tasks | Change |
| --- | --- | --- |
| Prompts | P66, P68–P74 | A full English creation prompt for all 50 directions; the prompts README is in English |
| Gallery | P67, P81 | An empty filter result lists each active filter with the count it would bring back; gallery copy rewritten in plain sentences |
| Brands and images | P75–P79 | Seven demo brands that matched real names were renamed; Ember Course Room got its own B hero; Still Sanctuary repeats fewer photographs; Midnight Vestibule and Architectural Monograph use generated images instead of photographs of real buildings |
| Copy | P80–P86 | An audit of AI-template signs, then all 50 directions rewritten: plain headlines with a fact from the page, the direction's own vocabulary instead of "quiet / calm / slow", one footer line plus one note per form instead of repeated disclaimers, no arrows on in-page links, fewer em dashes, no real city names |
| Visual | P87 | The cursor-following glow was removed where it was only atmosphere (Acoustic Sculpture, Midnight Vestibule); decorative italic heading words are upright in nine directions |

Renamed demo brands (P75), each checked with a web search:

| Direction | Before | Now |
| --- | --- | --- |
| Pop Commerce | Loop | Tumbelo |
| Botanical Engraving | Folium | Sprigvane |
| Soft Spatial | Morrow | Halvessa |
| Y2K Chrome | Phase | Vellaxis |
| Data Observatory | Tallyhall | Numberell |

`tests/copy-tells.test.mjs` now checks every reference page, the gallery
template and the rendered gallery for formula headlines, "not just",
arrow-only links and em-dash density. Its backlog is empty: every direction
passes with no exemption. Before/after headline tables are in
`docs/evidence/P82.md` to `P86.md`.

Style IDs and file paths are unchanged and no direction was removed, so 1.5.0
is a minor release. Package and lock versions are canonical render inputs:
all 200 preview records are regenerated with the pinned renderer through
**Regenerate canonical previews**, not edited by hand.

Original code, SVG geometry and synthesized sound remain MIT. Photographs and
AI-generated images keep their documented rights; `assets.json`, each style's
`assets/RIGHTS.txt` and `THIRD_PARTY_NOTICES.md` apply. Bundled fonts ship
with their full OFL text. References have real local interactions but no
production order, booking, payment or contact backend.

## Reproduce the source checks

Use Ubuntu 24.04 x64, Node 24.19.0 and the committed npm lockfile. The locked
Playwright uses Chromium headless shell 151.0.7922.34.

```sh
git clone https://github.com/lmatukas/web-style-atlas.git
cd web-style-atlas
npm ci --ignore-scripts --no-audit --no-fund
node scripts/ci-scope.mjs --full
node scripts/ci.mjs validate
npm run check
npx playwright install --with-deps --only-shell chromium
node scripts/ci.mjs browser
git diff --exit-code
```

## Manual publication procedure

After this release PR is merged with successful checks, open
[Actions → Verify release and optionally publish Pages](https://github.com/lmatukas/web-style-atlas/actions/workflows/release.yml)
and choose **Run workflow → main → publish = true**. The workflow checks that
`package.json`, this file and the CHANGELOG agree on the version, verifies every
direction has two variants and four current previews, then deploys `dist/`.

After **verify** and **deploy** succeed, open the live URL and check: 50 cards,
the gallery hero copy, an empty filter result, A/B and mobile previews, prompt
copy for a direction that had no prompt in 1.4.0, and one rewritten reference
page. Record the run, deployed SHA and observations in a section below.
