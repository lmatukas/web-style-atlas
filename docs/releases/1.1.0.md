## Reproduce the source checks

Use Ubuntu 24.04 x64, Node 24.19.0 and the committed npm lockfile. The locked
Playwright 1.62.1 uses Chromium headless shell 151.0.7922.34.

```sh
git clone https://github.com/lmatukas/web-style-atlas.git
cd web-style-atlas
npm ci --ignore-scripts --no-audit --no-fund
node scripts/ci-scope.mjs --full
node scripts/ci.mjs validate
npm run check
npx playwright install --with-deps --only-shell chromium
node scripts/ci.mjs browser
git diff --exit-code
npm run dev -- --base /web-style-atlas/
```

The local gallery exposes all 39 source directions immediately. Choosing any of
the fifteen new directions enables **Copy full creation prompt** and its exact
A/B text/manual fallback. Fill in the retained project fields before handing it
to an agent. The canonical full prompt is distributed locally under `prompts/`;
the aggregate private source input is not part of the repository or output.
