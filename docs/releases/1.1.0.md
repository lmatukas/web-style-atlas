## Reproduce the source checks

Use Ubuntu 24.04 x64, Node 24.19.0 and the committed npm lockfile. The locked
Playwright 1.62.1 uses Chromium headless shell 151.0.7922.34.

```sh
git clone https://github.com/lmatukas/web-style-atlas.git
cd web-style-atlas
npm ci --ignore-scripts --no-audit --no-fund
node scripts/ci-scope.mjs --full
node scripts/ci.mjs validate
npm run check
npx playwright install --with-deps --only-shell chromium
node scripts/ci.mjs browser
git diff --exit-code
npm run dev -- --base /web-style-atlas/
```

The local gallery exposes all 39 source directions immediately. Choosing any of
the fifteen new directions enables **Copy full creation prompt** and its exact
A/B text/manual fallback. Fill in the retained project fields before handing it
to an agent. The canonical full prompt is distributed locally under `prompts/`;
the aggregate private source input is not part of the repository or output.

## Manual publication procedure

After the P18 PR is merged with successful checks, open
[Actions → Verify release and optionally publish Pages](https://github.com/lmatukas/web-style-atlas/actions/workflows/release.yml)
and select **Run workflow → main → publish = true → Run workflow**.

The owner has already authorized publication. The connected GitHub tool has no
workflow-dispatch operation; this is the required execution action, not another
approval request. Start a new run rather than rerunning a historical 1.0.0 run.
The existing workflow performs the complete 1.1.0 / 39 / 78 / 156 gate before
uploading `dist/` and deploying. It remains manual only, with bounded Linux jobs,
read-only source permissions, separate deployment permissions, no new cache and
one-day artifact retention. Claim, tracking and ordinary documentation merges
do not publish.

For a later authorized release, after both **verify** and **deploy** succeed,
open the actual environment URL and record the new run and deployed source SHA.
Perform actual live card-count, search/reset, A/B, mobile, full-prompt-copy and
working-reference checks before accepting publication. Update the frozen version
assertion for that release first.

For 1.1.0, the owner completed this manual publication in run 39659487799 and
P18 recorded the actual live observations above. No separate tag or GitHub
Release was created. Ordinary documentation and tracking commits do not deploy.
