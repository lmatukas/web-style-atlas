# P88 — Release 1.5.0: copy without AI-template signs

## Goal

Publish 1.5.0 after P80–P87: every direction's copy rewritten without the
AI-template signs found in the audit, the gallery copy fixed, and the
decorative cursor glow and italic heading accents removed.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`docs/audits/ai-template-audit.md`, `docs/releases/1.4.0.md` as the format
example.

## Depends on

P87 (canonical docs/progress.json).

## Allowed changes

`package.json`, `package-lock.json` version, `CHANGELOG.md`,
`docs/releases/1.5.0.md`, `README.md`, `README.lt.md`, `START_HERE.md`,
`gallery/README.md`, regenerated preview records, `docs/evidence/P88.md`.

## Steps

1. Confirm `COPY_BACKLOG` is empty and P81–P87 are done.
2. Version 1.5.0, CHANGELOG, release notes in neutral wording.
3. Full canonical preview render through the workflow (the version is a
   render input).
4. Open the PR and merge on green CI. After the owner runs **Verify release
   and optionally publish Pages** with `publish = true`, record the run and
   live checks in the release notes.

## Checks

`node scripts/release-gate.mjs` (50 / 100 / 200), `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, release
workflow `verify` and `deploy`.

## Done when

1.5.0 merged; published by the owner's run; live gallery checked and recorded.

## Out of scope

New directions, fonts (the P87 proposal), publishing without the owner's run.

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P88.md`.
