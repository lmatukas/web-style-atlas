# P81 — Gallery copy and copy-lint guard

## Goal

Rewrite the public gallery's copy so it no longer uses the AI-template signs
listed in `docs/audits/ai-template-audit.md` (F10), and add a test that stops
those patterns from coming back while P82–P86 rewrite the directions.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/audits/ai-template-audit.md`,
`gallery/template.html`, `gallery/README.md`, `tests/browser/gallery.test.mjs`.

## Depends on

P80 (canonical docs/progress.json).

## Allowed changes

`gallery/template.html`, `gallery/gallery.css`, `gallery/README.md`,
`tests/copy-tells.test.mjs` (new), gallery tests that assert old text,
`docs/evidence/P81.md`.

## Steps

1. Rewrite the gallery copy: a plain hero sentence about what the atlas is
   and does; no italic accent word, no fragment pairs, no "not just", no
   all-caps label above every heading, no arrow on internal links. Keep the
   three how-to steps only as real instructions, without decorative numbers.
2. Add `tests/copy-tells.test.mjs`. For every reference page and the gallery,
   fail on: an h1/h2 made of two or more sentences of four words or fewer;
   "Less X. More Y." / "Not X. More Y." / "N nouns. One noun." headings;
   "not just"; more than one em dash per 300 words. Directions that still
   fail are listed in `COPY_BACKLOG`, which may only shrink (same pattern as
   `LITHUANIAN_BACKLOG`). The gallery is never in the backlog.
3. Regenerate previews only if a style preview input changed (it should not).

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests, gallery
browser tests; read the new gallery copy aloud.

## Done when

The gallery passes the new test, the backlog lists exactly the failing
directions, PR merged with green CI.

## Out of scope

Direction pages (P82–P86).

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P81.md`.
