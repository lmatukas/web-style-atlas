# P02 — Validavimas ir deterministinis generavimas

## Goal

Validate authored sources and generate deterministic tokens and compact indexes.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 6, 7, 9, 13.

## Depends on

P01 (canonical docs/progress.json).

**Priklauso:** P01.

## Allowed changes

`scripts/validate.mjs`, `scripts/build.mjs`, reikalingus mažus pagalbinius modulius, `tests/`, npm scripts ir lockfile.

## Steps

naudoti patikimą YAML parserį ir JSON Schema validatorų; nerašyti savo YAML parserio. Generuoti `tokens.css`, JSON ir Markdown indeksus. `build` iškviečia šaltinių validaciją, bet nereikalauja dar neegzistuojančių preview. `check` tikrina ir publikavimui reikalingus generated failus. Šablonas neįtraukiamas į katalogą.

## Checks

vienas tinkamas fixture, netinkamas ID, trūkstamas laukas, blogas enum, nežinomas failo kelias, kontrasto klaida; du build paleidimai duoda vienodus tekstinius rezultatus. Keičiant tokeną pasikeičia generated CSS. Testai tikrina kontraktą, ne vien atkartojamą implementacijos detalę.

## Done when

aiškios klaidos su failo keliu ir lauku; draft/ready elgsena apibrėžta; nėra nereikalingo framework.

## Out of scope

Do not create finished design styles, browser rendering, the gallery or CI. Never include templates/style as a catalogue entry.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
