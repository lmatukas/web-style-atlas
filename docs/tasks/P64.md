# P64 — Release 1.4.0: every direction in English

Publish 1.4.0 after all 26 conversions: 50 directions, all pages and prompts
in English.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`docs/english-conversion-plan.md` (section "P64 release 1.4.0"),
`docs/releases/1.3.0.md` as the format example.

`package.json`, `package-lock.json` version, `CHANGELOG.md`,
`docs/releases/1.4.0.md`, `README.md`, `README.lt.md`, `START_HERE.md`,
`gallery/README.md`, `tests/language.test.mjs` (empty backlog), regenerated
preview records, `docs/evidence/P64.md`.

## Steps

1. Confirm `LITHUANIAN_BACKLOG` is empty, every reference page is `en`, every
   brief is `en`, and `node scripts/distinctiveness.mjs` shows no
   `footer-boilerplate` warning.
2. Version 1.4.0, CHANGELOG, release notes in neutral wording.
3. Full canonical preview render through the workflow.
4. Open the PR. After the owner merges and runs **Verify release and
   optionally publish Pages** with `publish = true`, record live checks
   (50 cards, English filter, one converted reference page) in the release
   notes and mark done.

`node scripts/release-gate.mjs` (50 / 100 / 200), `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, release
workflow `verify` and `deploy`.

## Done when
