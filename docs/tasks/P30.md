# P30 — Pataisa: S55 B fasadas ir rezervacijos veiksmas

## Goal

B fasadas bent 70 % pirmo ekrano; fiksuotas rezervacijos skirtukas nekonkuruoja su kambario veiksmu. Užregistruota P27 audite kaip P27-A02
([#139](https://github.com/lmatukas/web-style-atlas/issues/139)).

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`core/luxury-guide.md`, `docs/evidence/luxury-review.md` (S55 eilutės),
issue #139.

## Depends on

P27 (canonical docs/progress.json).

## Allowed changes

`styles/midnight-vestibule/**`, sugeneruoti katalogo failai (`npm run build`), `docs/evidence/P30.md`.

## Steps

1. Atkurti issue aprašytą matavimą ar klaidą dabartiniame šaltinyje.
2. Ištaisyti priežastį, išlaikant kryptį, A/B skirtumą ir veikiančias paslaugas.
3. Perskaičiuoti tą patį matavimą, paleisti patikras ir atnaujinti PNG.

## Checks

Tikslūs priėmimo kriterijai yra issue #139. Bent: `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, paveikto
stiliaus QA, perskaičiuoti matavimai ir peržiūrėti atnaujinti PNG.

## Done when

Issue kriterijai įrodyti `docs/evidence/P30.md`; PR sujungtas; issue uždarytas.

## Out of scope
