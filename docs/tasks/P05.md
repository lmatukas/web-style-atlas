# P05 — Atranka ir universali agento instrukcija

## Goal

Implement style selection and portable consumer instructions for agents.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 3, 4, 7.5.

## Depends on

P04 (canonical docs/progress.json).

**Priklauso:** P04.

## Allowed changes

`START_HERE.md`, `core/selection-guide.md`, `core/skill/SKILL.md`, `core/agent-entry.md`, atrankos fixtures.

## Steps

įrašyti 3 skyriaus eigą, taupų failų skaitymą, vieno klausimo principą, aiškų pasirinkimo režimą ir autopasirinkimą. Atskirk repo priežiūros instrukciją nuo stiliaus naudojimo kitame projekte. `AGENTS.md` neturi visada liepti pridėti stilių, kai vartotojas tik nori sukurti svetainę.

## Checks

bent 6 scenarijai: stilius nenurodytas; konkretus ID; „pasirink pats“; nėra nuotraukų; esamas prekės ženklas; norimas ID neegzistuoja. Pastaruoju atveju agentas nesiūlo išgalvoto katalogo įrašo.

## Done when

pasirinkimas remiasi tik egzistuojančiais ready įrašais, pateikia tikras nuorodas ir neteigia matęs neatvertų vaizdų.

## Out of scope

Do not add AI APIs or vector databases, invent unavailable styles or overwrite the maintenance routing and cost policy.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
