# P33 — Pataisa: S60 B žemėlapio aukštis

## Goal

Pats B žemėlapis, ne jo apvalkalas, pasiekia slenkstį. Užregistruota P27 audite kaip P27-A05
([#142](https://github.com/lmatukas/web-style-atlas/issues/142)).

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`core/luxury-guide.md`, `docs/evidence/luxury-review.md` (S60 eilutės),
issue #142.

## Depends on

P27 (canonical docs/progress.json).

## Allowed changes

`styles/openwater-deck/**`, sugeneruoti katalogo failai (`npm run build`), `docs/evidence/P33.md`.

## Steps

1. Atkurti issue aprašytą matavimą ar klaidą dabartiniame šaltinyje.
2. Ištaisyti priežastį, išlaikant kryptį, A/B skirtumą ir veikiančias paslaugas.
3. Perskaičiuoti tą patį matavimą, paleisti patikras ir atnaujinti PNG.

## Checks

Tikslūs priėmimo kriterijai yra issue #142. Bent: `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, paveikto
stiliaus QA, perskaičiuoti matavimai ir peržiūrėti atnaujinti PNG.

## Done when

Issue kriterijai įrodyti `docs/evidence/P33.md`; PR sujungtas; issue uždarytas.

## Out of scope

Kitų krypčių taisymai; slenksčių švelninimas; realių prekių ženklų minėjimas.

## Tracking and handoff
