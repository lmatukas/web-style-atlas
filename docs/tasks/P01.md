## Goal

Inspect the existing scaffold and establish the versioned data contract.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 1, 2, 6, 7, 10, 12.

## Depends on

None (canonical docs/progress.json).

**Priklauso:** nuo pateikto checkout arba leidimo sukurti tuščią projektą.

**Skaityti:** šį planą, esamus repo instrukcijų failus ir `package.json`, jei yra.

## Allowed changes

karkasą, `schema/`, `templates/style/`, `core/vocabularies.json`, `docs/implementation-plan.md`, `docs/tasks/`, `docs/progress.json`, `docs/decisions.md`, `.gitignore`, licencijos failus, `package.json`.

## Steps

užrašyti realų repo, šaką ir HEAD; patikrinti necommitintus vartotojo pakeitimus; išsaugoti šį planą repo; apibrėžti 7 skyriaus schemas; sukurti 38 korteles ir jų priklausomybes. Node versiją parinkti pagal tuo metu palaikomą LTS ir įrašyti repo konfigūracijoje. Esamą teisingą darbą išsaugoti. Savininko vardo ar repo URL neišgalvoti.

## Done when

visos kortelės ir ID sutampa su planu, šablono JSON ir YAML parsina, kiekviena privaloma schema egzistuoja, progresas tiksliai atitinka realybę. Dar nekurti 24 stilių ir nebandyti jų pažymėti baigtais.

## Bootstrap already exists

The plan, 38 cards, queue helper and tracking protocol are already present. Preserve them and all current task states. P01 still needs the product schemas, template, vocabulary, package setup and actual scaffold inspection. Do not mark P01 done just because the task cards exist. Preserve the existing MIT copyright holder.

## Checks

Compile every JSON Schema; parse and validate the template JSON/YAML; verify all 38 task IDs, card fields and dependency links; run the existing queue tests and board check. Record the actual repository, branch, HEAD and clean-worktree inspection.

## Out of scope

Do not implement styles, the catalogue generator, renderer, gallery, CI or agent adapters. Do not reset existing task states or replace the MIT copyright holder.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
