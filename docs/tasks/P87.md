# P87 — Optional visual pass: glow, italic accents, fonts

## Goal

Handle the visual findings F7–F9 of `docs/audits/ai-template-audit.md` after
the copy is fixed. This task is optional: the owner decides whether to run
it.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/audits/ai-template-audit.md`,
`core/luxury-guide.md`, the creation prompts of the affected directions.

## Depends on

P86 (canonical docs/progress.json).

## Allowed changes

Reference pages, CSS, scripts, `style.md`, prompts, QA, fonts with rights
records and regenerated previews of the affected directions;
`docs/evidence/P87.md`.

## Steps

1. Cursor-following glow (F8): keep it where the pointer controls the subject
   (Light Environments, Woven Field, Scent Ritual and any other whose prompt
   makes it the main interaction); elsewhere replace it with a finite,
   purposeful episode or remove it, and update the prompt and runtime QA.
2. Italic accent words (F7): keep italics only where they are a documented
   type signature; remove decorative ones from headings.
3. Fonts (F9): propose a licensed, bundled font pairing for each system-font
   direction that needs one to look distinct; add only after the owner
   agrees, with OFL files and rights records.

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests, QA,
runtime and browser QA, distinctiveness; previews through the workflow.

## Done when

The owner-approved changes are merged with green CI.

## Out of scope

Copy (P81–P86).

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P87.md`.
