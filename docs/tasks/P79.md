# P79 — Architectural Monograph: invented houses and generated photographs

## Goal

Architectural Monograph studies two real historic houses with public-domain
photographs, real architects and real places. The public atlas should use
only invented content, so rebuild the demonstration around two invented
houses with generated photographs, as its creation prompt (P74) already
describes.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `prompts/architectural-monograph/prompt.en.md`,
`styles/architectural-monograph/style.md`, `layouts.json`, `assets/RIGHTS.txt`,
`THIRD_PARTY_NOTICES.md`.

## Depends on

P78 (canonical docs/progress.json).

## Allowed changes

`styles/architectural-monograph/**` (reference pages, CSS, `plan.svg`, assets,
`assets.json`, `RIGHTS.txt`, `style.md`, `layouts.json`, regenerated previews),
`catalog/previews-manifest.json`, `THIRD_PARTY_NOTICES.md`,
`docs/evidence/P79.md`.

## Steps

1. Invent two houses, their architects and places; web-check every new name.
2. Replace both photographs with asset bank M-03 (winter timber house) and
   M-04 (brick and render house on a slope), in the style's monochrome
   treatment; record tool, date, full prompts and modifications from
   `M-01-M-04-generation-record.json`.
3. Rewrite titles, dossier, captions, alt text, readings, index, `style.md`
   and `layouts.json`; captions credit the images honestly as AI-generated.
4. Redraw `plan.svg` for the first house.
5. Delete the old files and records; remove them from `THIRD_PARTY_NOTICES.md`.

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests, browser QA,
distinctiveness; before/after preview review; no real building, architect,
place or photographer name left in the style folder or the notices.

## Done when

The direction shows only invented houses with recorded rights, PR merged with
green CI.

## Out of scope

History files, other styles.

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P79.md`.
