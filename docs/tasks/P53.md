## Steps

1. Translate all visible and script-written text in A and B; `lang="en"`.
2. Update QA strings and selectors without dropping a single case.
3. Translate `style.md`/`tokens.json` prose; move and translate the prompt;
   update `prompts/index.json`.
4. Remove `light-environments` from `LITHUANIAN_BACKLOG`.
5. Run the checks, regenerate this style's previews in the workflow, inspect
   all four PNGs against the previous ones.

## Checks

As listed in the plan's "Checks" section, with `node styles/light-environments/qa.mjs`.
Record each command and result in `docs/evidence/P53.md`, plus a short
before/after note for the four previews and any text-fit fix.

## Done when

No Lithuanian text left in the style except the technical glyph line (and
invented brand letters); all checks pass; previews regenerated and inspected;
PR merged.

## Out of scope

Other styles; redesign; new interactions; changing shared scripts. If a shared
script blocks the conversion, record a blocker instead of editing it.
