# P77 — Still Sanctuary: fewer repeated photographs

## Goal

Still Sanctuary shows the same three photographs several times: the forest
image is A's hero and region 01, and the lake image is B's hero and the second
villa card. Replace the repeats with asset bank images and recompress the
oversized pavilion file.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `core/luxury-guide.md`,
`prompts/still-sanctuary/prompt.en.md`, `styles/still-sanctuary/style.md`,
`styles/still-sanctuary/assets/RIGHTS.txt`.

## Depends on

P76 (canonical docs/progress.json).

## Allowed changes

`styles/still-sanctuary/**` (reference pages, assets, `assets.json`,
`RIGHTS.txt`, `style.md`, QA, regenerated previews),
`catalog/previews-manifest.json`, `docs/evidence/P77.md`.

## Steps

1. A region 01: asset bank D-01 (foggy pine forest) instead of the repeated
   hero forest.
2. B second villa card: asset bank J-02 (steaming stone bath); rewrite that
   card's copy and alt text as a villa with a private stone bath.
3. Recompress `pavilion.webp` (638 KB) for the sizes it is shown at.
4. Keep the ritual mapping (morning forest, day pavilion, evening lake) the
   style prompt requires; keep palette, type and motion.
5. Record the new files in `assets.json` and `RIGHTS.txt` with the full
   prompts from the bank manifest.

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests, the style's
QA, runtime and browser QA, distinctiveness; before/after preview review.

## Done when

No photograph repeats inside one section sequence as described above, total
photographs stay under 1.5 MB, PR merged with green CI.

## Out of scope
