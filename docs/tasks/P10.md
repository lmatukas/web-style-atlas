# P10 — Realus naudojimo kitame projekte bandymas

## Goal

Test atlas consumption in real independent website projects.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 3, 9, 16.

## Depends on

P09, P07, S12 (canonical docs/progress.json).

**Priklauso:** P09, P07 ir S12.

## Allowed changes

`docs/benchmarks/`, konkrečias nustatytas instrukcijų ar stilių klaidas.

## Steps

parengti 3 fiksuotus briefus: paslaugų įmonė be nuotraukų; fotografijomis paremtas portfolio; informacijos ar produktų katalogas. Su realiai prieinamu tiksliniu mažesniu agentu išbandyti pasirinkimą ir svetainės įgyvendinimą atskirame laikiname projekte. Bent vieną tą patį briefą įgyvendinti 3 skirtingomis katalogo kryptimis. Papildomai išbandyti vieną platformos adaptaciją, kai pakeičiama technologija, bet išlaikomi stiliaus bruožai.

## Done when

agentas surado teisingus failus, pasiūlė egzistuojančius stilius, išlaikė pasirinktus bruožus; trijų svetainių kompozicijos skiriasi. Įrašyti agentą, versiją/modelį, repo commit, tikslų promptą, kas iš tikrųjų paleista ir rezultatą. Jei tikslinio agento nėra, parengti bandymo paketą ir pažymėti `blocked` tik realaus bandymo dalį; nesukurti išgalvoto dialogo kaip įrodymo.

## Checks

Execute all three fixed briefs with the available target agent, use three directions for one brief and run one platform adaptation. Record the exact prompts, agent/model versions, commit and observed results. Report unavailable runtimes honestly.

## Out of scope

Do not fabricate target-agent executions or conversations. An unavailable target runtime blocks the actual benchmark rather than proving success.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
