# P78 — Midnight Vestibule: generated night images instead of real buildings

## Goal

Midnight Vestibule uses four public-domain photographs of real buildings. The
public atlas should show only invented places, so replace all four with
generated asset bank images and remove the real-building records.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `core/luxury-guide.md`,
`prompts/midnight-vestibule/prompt.en.md`, `styles/midnight-vestibule/style.md`,
`styles/midnight-vestibule/assets/RIGHTS.txt`.

## Depends on

P77 (canonical docs/progress.json).

## Allowed changes

`styles/midnight-vestibule/**` (reference pages, CSS, scripts, assets,
`assets.json`, `RIGHTS.txt`, `style.md`, QA, regenerated previews),
`catalog/previews-manifest.json`, `docs/evidence/P78.md`.

## Steps

1. Hero: asset bank K-05 (bridge lamps in fog), with the 4:5 version on
   narrow screens; start the lamp glow on the bridge lamps.
2. Lobby chapter and Gallery suite: M-02 (night lobby, 4:5).
3. Restaurant under the dome and Dome apartment: M-01 (dome dining at night).
4. Surroundings and B's band: K-04 (distant window grid).
5. Rewrite copy and alt text that described the old photographs (arches,
   palms, towers); keep room names, prices and booking logic.
6. Delete the old files and their records; record the new files with the
   tool line, date and full prompt (K files from the bank manifest, M files
   from `M-01-M-04-generation-record.json`).

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests, the style's
QA, runtime and browser QA, distinctiveness; before/after preview review; no
real building, place or photographer name left in the style folder.

## Done when

All four photographs are generated images with recorded rights, PR merged
with green CI.

## Out of scope

History files, other styles.

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P78.md`.
