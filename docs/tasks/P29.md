# P29 — Pataisa: S53 B pirmo ekrano vaizdas

## Goal

B variante telefone ir planšetėje vaizdas turi užimti bent 70 % pirmo ekrano. Užregistruota P27 audite kaip P27-A01
([#138](https://github.com/lmatukas/web-style-atlas/issues/138)).

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`core/luxury-guide.md`, `docs/evidence/luxury-review.md` (S53 eilutės),
issue #138.

## Depends on

P27 (canonical docs/progress.json).

## Allowed changes

`styles/luminous-cut-vitrine/**`, sugeneruoti katalogo failai (`npm run build`), `docs/evidence/P29.md`.

## Steps

1. Atkurti issue aprašytą matavimą ar klaidą dabartiniame šaltinyje.
2. Ištaisyti priežastį, išlaikant kryptį, A/B skirtumą ir veikiančias paslaugas.
3. Perskaičiuoti tą patį matavimą, paleisti patikras ir atnaujinti PNG.

## Checks

Tikslūs priėmimo kriterijai yra issue #138. Bent: `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, paveikto
stiliaus QA, perskaičiuoti matavimai ir peržiūrėti atnaujinti PNG.

## Done when

Issue kriterijai įrodyti `docs/evidence/P29.md`; PR sujungtas; issue uždarytas.

## Out of scope

Kitų krypčių taisymai; slenksčių švelninimas; realių prekių ženklų minėjimas.

## Tracking and handoff
