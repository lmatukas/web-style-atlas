# P69 — Full creation prompts: editorial group

## Goal

Write a full English creation prompt for four ready directions that only have
the short selection prompt, and link it so the gallery offers
"Copy full creation prompt". Part of the series P69–P74 that brings every
ready direction to a full prompt.

| Style | Origin task (`task_id`) |
| --- | --- |
| `editorial-journal` | S02 |
| `newspaper-ledger` | S14 |
| `field-notes` | S09 |
| `botanical-engraving` | S19 |

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `prompts/README.md`,
`schema/prompt-briefs.schema.json`, two existing prompts as format models
(e.g. `prompts/scent-ritual/prompt.en.md`, `prompts/woven-field/prompt.en.md`),
and for each style: `style.md`, `layouts.json`, `tokens.json`, both reference
pages and its scripts.

## Depends on

P68 (canonical docs/progress.json).

## Allowed changes

`prompts/<id>/prompt.en.md` for the four styles, their entries in
`prompts/index.json`, the `prompt_path` line in each `style.md`, the prompt
count in `README.md` and `README.lt.md`, `docs/evidence/P69.md`.

## Steps

1. For each style, write `prompts/<id>/prompt.en.md` in the same structure as
   the existing prompts: title line, "Adapt to the project" fields, the exact
   line `- Composition: [A OR B; default A].`, a demonstration paragraph with
   the style's invented demo brand, Composition A and B, "Original creative
   brief" (palette with hex values, type, layout, the real working function,
   motion with durations, mobile and reduced-motion rules) and
   `## Final check`. Describe what the reference pages actually do; never
   promise a feature they do not have.
2. Plain English, no real company, website, building or person names; demo
   names must be the style's existing invented names (web-check any new one
   and record the date).
3. Add a `prompts/index.json` entry per style with the origin `task_id` from
   the table, matching `variants`, `signature`, `acceptance`, a valid
   `enhancement` value and at least one real `closest_styles` ID.
4. Add `prompt_path: prompts/<id>/prompt.en.md` to each `style.md`.
5. Update the full prompt count in `README.md` and `README.lt.md`.

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests, gallery and
creation-prompt browser tests. In the gallery, open each of the four styles,
switch A/B and confirm the copied prompt has the chosen composition filled in.

## Done when

All four styles copy a full creation prompt that matches their working
examples; PR merged with green CI.

## Out of scope

Reference pages, assets, previews, other styles.

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P69.md`.
