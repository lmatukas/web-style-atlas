# P28 — Leidimas 1.3.0: 50 krypčių, naujos pirmos

## Goal

Paruošti ir publikuoti 1.3.0 su 50 krypčių. Galerijoje 11 naujų prabangos
krypčių rodomos pirmos su žyma „Nauja“.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`docs/releases/1.2.0.md` (procedūra), `docs/luxury-expansion-plan.md`,
`scripts/release-gate.mjs`, `gallery/`, fresh `docs/progress.json`.

## Depends on

P27, P29, P30, P31, P32, P33, P34, P35, P36 (canonical docs/progress.json).

## Allowed changes

`gallery/**`, `core/vocabularies.json` arba katalogo laukas rikiavimui,
susiję testai, `package.json`, `package-lock.json`, `CHANGELOG.md`,
`docs/releases/1.3.0.md`, `README.md`, `README.lt.md`, `START_HERE.md`,
`docs/evidence/P28.md`.

## Steps

1. Pridėti rikiavimo ir „Nauja“ žymos mechanizmą: naujos 11 krypčių pirmos,
   tada likusios esama tvarka. Testas tikrina tvarką.
2. Versija 1.3.0, CHANGELOG ir `docs/releases/1.3.0.md` santūriu tonu, be
   prekių ženklų.
3. Po versijos pakeitimo perkurti visas peržiūras kanoniniu workflow.
4. Po sujungimo savininkas paleidžia „Verify release and optionally publish
   Pages“ su `publish = true`.
5. Patikrinti gyvą svetainę: 50 krypčių, naujos pirmos, paieška, A/B, mobilus
   vaizdas, prompto kopija; įrašyti į leidimo aprašą.

## Checks

1. `node scripts/release-gate.mjs` rodo 50 / 100 / 200
2. `npm run validate`, `npm run build`, `npm run check`, unit testai
3. Leidimo workflow `verify` ir `deploy` sėkmingi

## Done when

1.3.0 publikuotas, gyva galerija rodo 50 krypčių su naujomis pirmose vietose,
patikros įrašytos, PR sujungti.

## Out of scope

Naujų krypčių nekurti; publikuoti tik savininkui patvirtinus.

## Tracking and handoff

Laikytis `docs/WORKFLOW.md`: nuotolinis claim, vienas darbas, vienas PR,
įrodymai `docs/evidence/P28.md`. `done` tik po sujungimo.
