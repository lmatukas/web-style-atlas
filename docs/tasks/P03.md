# P03 — Renderinimas ir preview generavimas

## Goal

Render four reproducible previews per style and record their provenance.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 8, 9, 13.

## Depends on

P02 (canonical docs/progress.json).

**Priklauso:** P02.

## Allowed changes

`scripts/previews.mjs`, minimalų vietinį serverį, preview manifest schemą, browser testų konfigūraciją, npm scripts.

## Steps

priimti `--style <id>` ir `--all`; generuoti 4 konkretaus stiliaus PNG; laukti vietinių išteklių; išjungti animacijas; registruoti turinio hash ir render aplinką. Fixture puslapyje įrodyti, kad PNG atsiranda ir yra skaitomas. Užfiksuoti vieną canonical aplinką CI preview generavimui.

## Done when

pakeitus CSS ar assetą senas manifest atmetamas; nepavykęs render nepalieka sėkmės įrašo; šrifto ar paveikslo užkrovimo klaida matoma. Browser nepasiekiamas = aiški `not_run` būsena, ne netikras PASS.

## Checks

Render a fixture and read the PNG. Prove changed CSS/assets invalidate the manifest, resource-load failures are visible and failed rendering leaves no successful manifest record. Record browser unavailability as not_run.

## Out of scope

Do not create finished styles, the gallery or a CI deployment. Do not claim a render passed when the browser is unavailable.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
