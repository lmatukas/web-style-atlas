# P11 — Vieša dokumentacija ir papildymo eiga

## Goal

Document public usage, limitations and the contribution workflow.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 1, 2, 14, 16.

## Depends on

P10 (canonical docs/progress.json).

**Priklauso:** P10; neįvykusio bandymo apribojimus galima dokumentuoti, bet neslėpti.

## Allowed changes

`README.md`, `README.lt.md`, `CONTRIBUTING.md`, `THIRD_PARTY_NOTICES.md`, PR šabloną.

## Steps

README pradžioje tikslas, preview galerija ir vienas kopijuojamas naudojimo promptas. Toliau – vietinis paleidimas, patikros, ribos, licencijos. CONTRIBUTING paaiškina naujo stiliaus skiriamumo kriterijus, šaltinių teises ir vieno stiliaus PR eigą.

## Done when

naujas vartotojas gali pradėti iš README be viso įgyvendinimo plano skaitymo. Nėra pažadų „garantuotai originalu“, nepagrįstų agentų palaikymo ar WCAG ženklelių.

## Checks

Follow the README from a fresh user perspective; check referenced commands and links, licensing instructions and limitations. Remove unsupported compatibility or accessibility claims.

## Out of scope

Do not promise guaranteed originality, untested agent support or unconditional accessibility conformance.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
