# P75 — Rename demo brands that match real names

## Goal

Seven demonstration names turned out to be used by real companies, labels,
bands or venues (found by the web checks in P69–P74). The atlas is public and
uses only invented names, so rename them everywhere they appear in the
current directions and prompts.

| Direction | Before | After |
| --- | --- | --- |
| Pop Commerce | Loop | Tumbelo |
| Botanical Engraving | Folium | Sprigvane |
| Soft Spatial | Morrow | Halvessa |
| Y2K Chrome | Phase | Vellaxis |
| Data Observatory | Tallyhall | Numberell |
| Humanist Service | Neighbour | Nearwell |
| Art Deco | The Atrium | The Ardelune |

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/evidence/P69.md` … `P74.md`,
`tests/neutral-names.test.mjs`.

## Depends on

P74 (canonical docs/progress.json).

## Allowed changes

For the seven directions: `styles/<id>/reference/*`, `styles/<id>/style.md`,
`prompts/<id>/prompt.en.md`, their `demo_brand` in `prompts/index.json`, and
regenerated previews and manifest. Also `tests/neutral-names.test.mjs`
(retired-name fingerprints) and `docs/evidence/P75.md`.

## Steps

1. Web-check each new name and record the date and result.
2. Replace every case form of the old name (title, upper, lower, spaced) in
   the allowed files; keep layout, copy length and behaviour.
3. Add the old names to the retired-name fingerprints.
4. Regenerate the seven directions' previews through the workflow.

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests, each
direction's QA, gallery browser tests; no old name left in the allowed files.

## Done when

No current page or prompt uses the seven old names; PR merged with green CI.

## Out of scope

History (CHANGELOG, release notes, old evidence), other directions.

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P75.md`.
