# P31 — Pataisa: S57 telefono monogramos kompozicija

## Goal

Telefone monogramos ir objekto kompozicija pasiekia matomo vaizdo slenkstį. Užregistruota P27 audite kaip P27-A03
([#140](https://github.com/lmatukas/web-style-atlas/issues/140)).

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`core/luxury-guide.md`, `docs/evidence/luxury-review.md` (S57 eilutės),
issue #140.

## Depends on

P27 (canonical docs/progress.json).

## Allowed changes

`styles/heirloom-weave-ledger/**`, sugeneruoti katalogo failai (`npm run build`), `docs/evidence/P31.md`.

## Steps

1. Atkurti issue aprašytą matavimą ar klaidą dabartiniame šaltinyje.
2. Ištaisyti priežastį, išlaikant kryptį, A/B skirtumą ir veikiančias paslaugas.
3. Perskaičiuoti tą patį matavimą, paleisti patikras ir atnaujinti PNG.

## Checks

Tikslūs priėmimo kriterijai yra issue #140. Bent: `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, paveikto
stiliaus QA, perskaičiuoti matavimai ir peržiūrėti atnaujinti PNG.

## Done when

Issue kriterijai įrodyti `docs/evidence/P31.md`; PR sujungtas; issue uždarytas.

## Out of scope

Kitų krypčių taisymai; slenksčių švelninimas; realių prekių ženklų minėjimas.

## Tracking and handoff

Laikytis `docs/WORKFLOW.md`. P28 priklauso nuo šios užduoties.
