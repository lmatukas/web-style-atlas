# P37 — English conversion: shared tooling

## Goal

Prepare the shared pieces every style conversion needs: English prompt paths,
a language backlog test, and an English luxury filter in the gallery.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`core/language-policy.md`, `docs/english-conversion-plan.md` (sections
"Why" and "P37 foundation").

## Depends on

P28 (canonical docs/progress.json).

## Allowed changes

`scripts/prompts.mjs`, `schema/prompt-briefs.schema.json`,
`tests/language.test.mjs` (new), `tests/creation-prompts.test.mjs`,
`gallery/template.html`, `gallery/README.md`, gallery tests that match the old
filter words, `prompts/README.md`, `core/language-policy.md`,
`docs/evidence/P37.md`. Do not convert any style here.

## Steps

1. Prompt path rule `prompts/<id>/prompt.<language>.md` (`lt` or `en`,
   matching `language`), with tests for valid `en`, mismatch and unknown
   language.
2. `tests/language.test.mjs` with `LITHUANIAN_BACKLOG` holding exactly these
   26 IDs: `obsidian-stage`, `luminous-cut-vitrine`, `escapement-nocturne`, `midnight-vestibule`, `still-sanctuary`, `heirloom-weave-ledger`, `velvet-members-hall`, `patina-auction-room`, `openwater-deck`, `scent-ritual`, `ember-course-room`, `acoustic-sculpture`, `balcony-builder`, `choreographic-stage`, `discovery-cabinet`, `light-environments`, `membrane-score`, `modular-light`, `repair-atlas`, `resonant-ribbon`, `rhythm-planner`, `seasonal-terrain`, `spine-editions`, `trail-composer`, `twilight-expedition`, `woven-field`.
   It fails on any `lt` page outside the list, on any listed ID that is
   already fully English, and on a style that mixes `lt` and `en` pages.
3. Gallery luxury filter: `Luxury`, `All directions`, `Luxury only`; remove
   `lang="lt"`; URL parameter unchanged.
4. Append the conversion rules pointer to `core/language-policy.md`.

## Checks

`npm run validate`, `npm run build`, `npm run check`,
`node --test tests/*.test.mjs`, `node --test tests/browser/gallery.test.mjs`
(gallery change), `node scripts/tasks.mjs check`. Gallery previews are not
affected; do not regenerate style PNGs.

## Done when

All four pieces merged; the language test passes with all 26 IDs in the
backlog; the built gallery shows the English filter.

## Out of scope

Converting styles; changing other validation rules; new directions.

## Tracking and handoff

Follow `docs/WORKFLOW.md`: remote claim, one task, one PR, evidence in
`docs/evidence/P37.md`. `done` only after merge.
