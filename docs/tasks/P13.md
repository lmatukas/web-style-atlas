# P13 — 24 stilių įvairovės ir naudojimo auditas

## Goal

Audit all twenty-four styles for visual distinction and real usability.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 4, 5, 9, 16.

## Depends on

S24, P10 (canonical docs/progress.json).

**Priklauso:** S24, P10.

## Allowed changes

`docs/evidence/catalog-review.md`, benchmark rezultatų atnaujinimą ir tik aptiktas stilių problemas.

## Steps

bendras 24 pagrindinių desktop ir mobile peržiūrų palyginimas; visų artimų porų vertinimas; likusių B variantų patikra. Pakartoti tik tuos P10 scenarijus, kuriuos paveikė turinio ar atrankos pokyčiai. Jei matosi ta pati kompozicija su skirtingomis dekoracijomis, taisyti konkretų įrašą.

## Done when

kiekvienas stilius turi artimiausio palyginimo įrodymą, priėmimo balą ir pažymėtą vizualinę peržiūrą. Metaduomenų skirtumai nepakeičia vaizdų patikros.

## Checks

Compare all 24 desktop/mobile A views and B variants, inspect every close pair and rerun only affected P10 scenarios. Record a rubric score and actual visual review per style.

## Out of scope

Do not substitute metadata differences for visual comparison or refactor unaffected styles.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
