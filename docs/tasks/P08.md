# P08 — CI ir kokybės vartai

Read first: `START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 9, 13.

Canonical dependencies: P07

**Priklauso:** P07.

**Keisti:** `.github/workflows/`, kokybės skriptus, tikslinius testus ir npm scripts.

**Veiksmai:** šaltinių validacija, generated failų drift, preview freshness, browser smoke, prieinamumo patikra. PR tikrinti pakeistus stilius ir tuos, kuriuos paveikė bendri failai; leidimui – visus. CI nekuria commitų ir neperrašo bazinių vaizdų, kad paslėptų klaidą.

**Priimti:** tyčinis sugadinimas lokaliame fixture sustabdo atitinkamą patikrą; darbiniai šaltiniai praeina; dokumentuota kaip atnaujinti preview canonical aplinkoje. „CI paruoštas“ ir „GitHub CI praėjo“ žymimi atskirai.

## Mandatory cost constraints

Read `docs/COST_POLICY.md` before implementation. Acceptance also requires one
standard-Linux PR validation path; no duplicate push/PR suite; no scheduled runs;
concurrency cancellation; bounded timeouts; changed-style/dependency selection;
no browser/deploy jobs for tracking-only changes; failure artifacts retained for
one day; no LFS, paid runners or automatic AI reviews. Preserve required statuses
with a cheap dispatcher if necessary. Verify the effective workflow triggers and
retention settings without running a needless full CI cycle.
