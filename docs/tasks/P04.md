# P04 — Trijų stilių pilotas ir kontrakto užfiksavimas

## Goal

Review the three-style pilot and freeze the proven v1 contract.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 4, 5, 9.

## Depends on

S01, S02, S03 (canonical docs/progress.json).

**Priklauso:** S01, S02, S03.

## Allowed changes

tik pilotinių stilių trūkumus, `core/quality-rubric.md`, `core/anti-generic.md`, `docs/evidence/pilot.md`; schemas keisti tik jei pilotas įrodė būtinybę.

## Steps

greta peržiūrėti 3 desktop ir 3 mobile pagrindines kompozicijas, po to B variantus. Vertinti 9 skyriaus rubrika. Patikrinti stilius ir su vienos neutralios paslaugų svetainės turiniu, kad skirtumą kurtų dizainas, ne vien skirtinga tema ar nuotrauka. Tam užtenka laikinų bandomųjų puslapių ir išvadų; nekurti papildomo generatoriaus.

## Done when

visi 3 praeina kokybės kriterijus; aprašyti artimiausių variantų skirtumai; nuo šiol schema v1 fiksuota. Masinė gamyba neprasideda, kol pilotas nepriimtas. Jei nėra vizualinio vertinimo galimybės, galima tęsti nepriklausomas technines korteles, bet ne dauginti nepatikrintą dizaino modelį.

## Checks

Inspect all pilot A/B desktop/mobile previews, complete the section 9 rubric and test the same neutral brief in each direction. Record actual visual observations, not only metadata.

## Out of scope

Do not start bulk style production before the pilot is accepted. Change schemas only when the pilot demonstrates the need.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
