# P80 — Audit: AI-template tells and project description

## Goal

Find where the atlas reads as a standard AI-generated website, using the
signs that designers and readers cite publicly, and plan the fixes. Bring the
project description up to date.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `README.md`, `README.lt.md`,
`gallery/template.html`.

## Depends on

P79 (canonical docs/progress.json).

## Allowed changes

`docs/audits/ai-template-audit.md` (new), `docs/tasks/P81.md` … `P87.md` and
their queue entries, `README.md`, `README.lt.md`, `docs/evidence/P80.md`.

## Steps

1. Collect the commonly cited signs of AI-generated websites and copy, with
   sources.
2. Scan all 50 directions and the gallery; mark exact places and rank them.
3. Write one reusable fix prompt and queue the fix tasks.
4. Correct stale or unsuitable statements in the READMEs.

## Checks

`npm run validate`, unit tests; every quoted example exists in the files.

## Done when

The audit, fix prompt and queued tasks are merged, and the READMEs match the
current state.

## Out of scope

Changing pages, styles or prompts (that is P81–P87).

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P80.md`.
