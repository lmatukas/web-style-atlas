# P06 — Galerijos pirmas veikiantis variantas

## Goal

Build the first usable static gallery using the three pilot styles.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 7.5, 8.

## Depends on

P05 (canonical docs/progress.json).

**Priklauso:** P05.

## Allowed changes

`gallery/`, galerijos build, atitinkamus browser testus.

## Steps

indeksas, paieška, filtrai, stiliaus detalės, A/B ir desktop/mobile perjungimas, tikri pavyzdžių keliai. Pradžiai naudoti 3 pilotinius stilius.

## Done when

veikia mobile, klaviatūra ir repo subpath; nėra JS klaidų ar tuščių preview; atidarius bet kurį pavyzdį veikia jo CSS ir assetai. `dist/` pilnai atkuriamas iš repo.

## Checks

Run gallery browser checks at mobile widths and under a repository subpath. Test keyboard navigation, asset requests, JavaScript errors and a clean rebuild of dist/.

## Out of scope

Do not build accounts, backend services, payments or a website generator; do not add more styles.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
