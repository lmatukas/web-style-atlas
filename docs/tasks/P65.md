# P65 — Correction: Lithuanian words left in converted luxury scripts

## Goal

The P38–P47 conversions searched for Lithuanian letters (ąčęėįšųūž) only.
A word audit against the pre-conversion source found visible strings with no
such letters that stayed Lithuanian: 3D fallback reasons, an SVG title, a pause
label and a result count. Translate them and add a test so this cannot slip
through again. Found during P48.

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`docs/english-conversion-plan.md` (sections "Conversion rules" and "Checks"),
`docs/evidence/P48.md`.

P48 (canonical docs/progress.json).

## Steps

1. Translate: `3D nepasiekiamas` (S53, S61), `3D neprieinamas` and
   `3D kontekstas prarastas` (S54), the S54 drawing title
   `originalus mechaninis laikrodis`, the S58 pause label `Pristabdyti`, and
   the S59 count `N objektai`.
2. Extend `tests/language.test.mjs`: styles outside `LITHUANIAN_BACKLOG` must
   not contain common Lithuanian interface words in their reference scripts.
3. Run each affected style's QA; regenerate and inspect its previews.
