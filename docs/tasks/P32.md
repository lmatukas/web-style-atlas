# P32 — Pataisa: S59 A telefono objektas

## Goal

A variante telefone objektas bent 70 % matomas pirmame ekrane. Užregistruota P27 audite kaip P27-A04
([#141](https://github.com/lmatukas/web-style-atlas/issues/141)).

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`core/luxury-guide.md`, `docs/evidence/luxury-review.md` (S59 eilutės),
issue #141.

## Depends on

P27 (canonical docs/progress.json).

## Allowed changes

`styles/patina-auction-room/**`, sugeneruoti katalogo failai (`npm run build`), `docs/evidence/P32.md`.

## Steps

1. Atkurti issue aprašytą matavimą ar klaidą dabartiniame šaltinyje.
2. Ištaisyti priežastį, išlaikant kryptį, A/B skirtumą ir veikiančias paslaugas.
3. Perskaičiuoti tą patį matavimą, paleisti patikras ir atnaujinti PNG.

## Checks

Tikslūs priėmimo kriterijai yra issue #141. Bent: `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, paveikto
stiliaus QA, perskaičiuoti matavimai ir peržiūrėti atnaujinti PNG.

## Done when

Issue kriterijai įrodyti `docs/evidence/P32.md`; PR sujungtas; issue uždarytas.

## Out of scope

Kitų krypčių taisymai; slenksčių švelninimas; realių prekių ženklų minėjimas.

## Tracking and handoff
