# P68 — Link the four unlinked luxury prompts

## Goal

Obsidian Stage, Luminous Cut Vitrine, Escapement Nocturne and Midnight
Vestibule have a full English creation prompt and a `prompts/index.json`
entry, but their `style.md` has no `prompt_path`. The gallery therefore offers
only the short selection prompt for them, although S52–S55 required the full
prompt to be reachable in the gallery.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `prompts/README.md`, `gallery/README.md`.

## Depends on

P67 (canonical docs/progress.json).

## Allowed changes

`styles/{obsidian-stage,luminous-cut-vitrine,escapement-nocturne,midnight-vestibule}/style.md`
(only the `prompt_path` line), `README.md` and `README.lt.md` (prompt count),
`docs/evidence/P68.md`.

## Steps

1. Add `prompt_path: prompts/<id>/prompt.en.md` to the YAML of each of the
   four `style.md` files, as in `styles/scent-ritual/style.md`.
2. Check each prompt still matches its reference pages (demo brand, A/B,
   signature function). Fix nothing else in this task; record gaps.
3. Update the full prompt count in `README.md` and `README.lt.md` (22 → 26).

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests and the
gallery browser tests; the built ready index lists 26 linked prompts.

## Done when

The four directions offer "Copy full creation prompt" in the gallery; PR
merged with green CI.

## Out of scope

Prompt texts, new prompts (P69–P74), previews.

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P68.md`.
