# P09 — Agentų adapteriai ir suderinamumo matrica

## Goal

Generate verified thin agent adapters and a candid compatibility matrix.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/progress.json`.

Required plan sections: 3.3, 6, 17.

## Depends on

P05, P08 (canonical docs/progress.json).

**Priklauso:** P05 ir P08; gali būti atliekama dar nebaigus S04–S12.

## Allowed changes

adapterių generatorių, tik patikrintus generuojamų adapterių kelius, `docs/compatibility.md` ir susijusias README instrukcijas.

## Steps

patikrinti oficialią Claude Code, Codex ir IBM Bob dokumentaciją. Registruoti datą, šaltinio URL, įrankio versiją, projekto ir išorinio katalogo naudojimo skirtumus. Sugeneruoti plonus adapterius iš vieno šaltinio. Išorinį katalogą naudojanti instrukcija turi turėti aiškų repo root nustatymą; nepalikti nutrūkstančių santykinių kelių nukopijavus skill.

## Checks

bazinis promptas veikia be adapterio; įrankio adapteris neperrašo tikslinio projekto esamų instrukcijų; generacija deterministinė. Kiekvienam įrankiui atskiri statusai: documented, generated, smoke-tested, not-tested. Nevadinti pilnai palaikomu vien dėl failo buvimo.

## Done when

suderinamumo matrica sąžininga; nedubliuojami 24 stilių tekstai kiekvienam adapteriui; nepasiekiamo agento runtime netampa kliūtimi universaliam naudojimui.

## Out of scope

Do not duplicate style content across adapters, overwrite a destination project’s instructions or claim runtime support based only on documentation.

## Tracking and handoff

Follow docs/WORKFLOW.md and docs/COST_POLICY.md. Update only this task’s record and regenerate docs/STATUS.md for tracking commits. Publish one implementation PR and evidence, set review on fresh remote main, then stop. Done requires a merged implementation and verified checks; never mark completion speculatively.
