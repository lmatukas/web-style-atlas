# P36 — Pataisa: P19 bendrų išteklių signalai

## Goal

Devyni plėtros bendrų išteklių signalai išspręsti su aiškiu, įrodytu sprendimu kiekvienam. Užregistruota P27 audite kaip P27-A08
([#145](https://github.com/lmatukas/web-style-atlas/issues/145)).

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/COST_POLICY.md`,
`core/luxury-guide.md`, `docs/evidence/luxury-review.md` (P19 eilutės),
issue #145.

## Depends on

P27 (canonical docs/progress.json).

## Allowed changes

`scripts/distinctiveness.mjs`, jo testai, paveiktų stilių ištekliai ir `RIGHTS.txt`, sugeneruoti failai, `docs/evidence/P36.md`.

## Steps

1. Atkurti issue aprašytą matavimą ar klaidą dabartiniame šaltinyje.
2. Ištaisyti priežastį, išlaikant kryptį, A/B skirtumą ir veikiančias paslaugas.
3. Perskaičiuoti tą patį matavimą, paleisti patikras ir atnaujinti PNG.

## Checks

Tikslūs priėmimo kriterijai yra issue #145. Bent: `npm run validate`,
`npm run build`, `npm run check`, `node --test tests/*.test.mjs`, paveikto
stiliaus QA, perskaičiuoti matavimai ir peržiūrėti atnaujinti PNG.

## Done when

Issue kriterijai įrodyti `docs/evidence/P36.md`; PR sujungtas; issue uždarytas.

## Out of scope

Kitų krypčių taisymai; slenksčių švelninimas; realių prekių ženklų minėjimas.
