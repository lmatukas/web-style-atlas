# P85 — De-template copy, batch 4

## Goal

Rewrite the page copy of ten directions so it no longer reads like a
standard AI-generated website (findings F1–F6 in
`docs/audits/ai-template-audit.md`), keeping each direction's design and
behaviour.

Directions: `organic-craft`, `membrane-score`, `luminous-cut-vitrine`, `kinetic-type`, `discovery-cabinet`, `twilight-expedition`, `trail-composer`, `institutional-clear`, `gallery-white-cube`, `botanical-engraving`.

## Read first

`START_HERE.md`, `docs/WORKFLOW.md`, `docs/audits/ai-template-audit.md`
(section 6 is the fix prompt to follow), and for each direction its
`style.md`, reference pages, scripts, `qa.mjs` and creation prompt.

## Depends on

P84 (canonical docs/progress.json).

## Allowed changes

For the ten directions: `styles/<id>/reference/*`, `styles/<id>/style.md`,
`styles/<id>/qa.mjs`, `prompts/<id>/prompt.en.md`, regenerated previews and
`catalog/previews-manifest.json`; `tests/copy-tells.test.mjs` (remove the ten
from `COPY_BACKLOG`); `docs/evidence/P85.md`.

## Steps

Follow the fix prompt in section 6 of the audit for each direction:
headlines, voice, one honest footer line plus notes beside real-looking
actions, labels, arrows, em dashes; no new claims. Update the creation prompt
and `style.md` where they quote or prescribe the old copy.

## Checks

`npm run validate`, `npm run build`, `npm run check`, unit tests (the ten
directions pass `tests/copy-tells.test.mjs`), each direction's QA, browser and
runtime QA; previews through the workflow; before/after headlines recorded.

## Done when

The ten directions pass the copy test without a backlog entry, their
functions and QA are unchanged, PR merged with green CI.

## Out of scope

Layout, palette, fonts, images, motion (see P87).

## Tracking and handoff

Follow `docs/WORKFLOW.md`. Evidence in `docs/evidence/P85.md`.
