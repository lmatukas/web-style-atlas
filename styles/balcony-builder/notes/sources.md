# Light selection source boundary

Read 2026-10-21: University of Maryland Extension, https://www.extension.umd.edu/resource/growing-vegetables-containers-and-salad-tables (updated September 10, 2026): warm-season tomato/pepper examples use 6–8 hours direct sun; lettuce/spinach examples use 3–5. Iowa State University, https://yardandgarden.extension.iastate.edu/how-to/growing-edible-plants-shady-areas (reviewed June 2025), explains full shade is unsuitable for productive edibles.

Only these general principles are paraphrased. No photographs, marks, measurements, schedules, yield promises or construction specifications are copied. Module counts and beginner/experienced guide choices are authored demonstration rules. The below-three-hours/unknown choice conservatively returns a light-observation concept, not a promised crop. Actual local species, season, pot capacity and balcony suitability require project-specific information.
