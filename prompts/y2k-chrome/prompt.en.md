## Original creative brief

Create your own visual expression: original copy, illustrations, composition and details. Use only your own or properly licensed assets. Do not carry over other brands, code, recognisable scenes or combinations of them. Mark the working demonstration name clearly as invented; use real facts only once the user provides reliable content.

The project is PHASE, an invented series of audio–visual editions imagined as objects from turn-of-the-century pop culture. Volume 02, "After the signal.", has three imagined tracks; volumes 03 and 04 are related object studies. There is no audio, playback, purchase or streaming: say so in the edition record. Never use borrowed album covers or stock renders.

Palette: a cool lilac-grey ground #dce0f0, a pale panel #f3f5ff, deep indigo text #1c1932, muted text #504a69, a violet accent #4b278e with white text, borders #716a87, a rust focus outline #77271e, and material tokens for the artwork only: silver light #ffffff, silver mid #b8c5e0, silver dark #3d4765 and violet #9f94d0. Use one blunt sans serif (Arial Black/Arial or a licensed grotesque) for oversized words and a monospace stack for identifiers like "PHASE OBJECT / 02". Chrome gradients stay inside illustrations; essential labels are never metallic gradient text.

Draw four original CSS or SVG material forms: a shaded reflective sphere, a tilted orbit ring with an open centre, a reflective disc and three parallel capsules. Label each by its form; hide spark marks.

Composition A, the release poster: a compact header ("PHASE / 02") with links (the release, collection, edition notes). A poster split between three stacked title lines ("AFTER THE SIGNAL."), one short line and an "Explore the edition" link, and the sphere-and-orbit composition, closed by a narrow transmission strip with a monospace identifier. Below, an editorial release introduction beside three numbered track rows with title and duration (01 Residual light 04:12, 02 Silver hour 05:08, 03 Return signal 03:40 — total 13:00), with no play buttons. A large slogan band changes the rhythm. A plain edition record and a native volume-notes disclosure finish the page, with a link to the collection.

Composition B, the collection: a wide headline ("OBJECTS FROM ANOTHER HOUR.") with a numbered index (02, 03, 04). Edition 02 gets the dominant sphere and a narrow record (object language, sequence: 3 imagined tracks · 13:00, a link to the release). Editions 03 (reflective disc, "Soft impact.") and 04 (parallel capsules, "Parallel light.") use horizontal object / title / number rows, each with a native disclosure listing its imagined sequence. A short collection record and a return link close the page.

Do not build a portal of tiny bevelled panels or animate every orbit. On a phone the title lines stay big but never overflow, the sphere follows the words at a size that fits, and collection rows stack object above text.

## Final check

Check 360, 390, 768 and 1440 px widths for both compositions. There is no required motion: content is present immediately; prefers-reduced-motion removes short transitions; no orbit animates continuously. Check keyboard focus, contrast on every real text background, the console and that there is no horizontal scrolling. A static screenshot alone does not prove that a control works; operate each one.

Functional acceptance: Release and collection links reach real sections; the numbered index reaches all three editions; volume disclosures work with a keyboard; text stays solid and selectable; no play, buy, stream or ticket control exists.

Mark the demonstration project clearly in the page footer.

Deliver a working preview, a summary of the checks actually run, the origin of assets and the remaining limits. Publish publicly only when the user asks. Finish the implementation; a plan alone is not a result.
