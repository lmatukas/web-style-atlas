# Preserve a direction, not a skin

The P04 pilot established three separate systems:

| Direction | Structural identity | Cosmetic imitation to reject |
|---|---|---|
| Swiss Grid | Unequal aligned columns, numbered service index, identity rail | A red hero above equal rounded cards |
| Editorial Journal | Literary masthead, departments, narrow essay with margin notes | Beige app cards with a serif heading |
| Neo Brutalist | Poster scale, exposed frames, bands, interactive programme | A yellow generic landing page with a black shadow |

Start with visitor task and information rhythm. Write 3–5 invariants before
coding. Create each direction's own composition; shared reset helpers are fine,
a universal layout with substituted tokens is not. A and B need different
content tasks and spatial arrangements while preserving those invariants.

Use semantic tokens for colors/type/spacing; geometry can remain direction
specific. Do not hide a second hardcoded CSS palette. Brand color is replaceable;
identity must survive a neutral brief. Low image dependency is legitimate when
typography and original CSS geometry carry the composition. Photography-led
directions need real rights-cleared photography, not placeholders.

Avoid fake forms, dead buttons, invented prices, unlicensed assets and excessive
motion. Native links and disclosures are often enough. A static example is still
a usable small page: local navigation, four meaningful sections and an honest
ending. Preserve meaningful content in mobile reading order instead of shrinking
an entire desktop spread.

A score is evidence-backed judgment, not a generator output. Inspect actual
previews, compare available neighbors, and report `not_run` when inspection is
unavailable. Do not multiply unreviewed layouts just to increase the catalogue.
